ah-fdmb — A report names things its ruleset doesn’t define

Chosen: a dialog over the map; the player picks the ruleset from a list; reporting is a second step behind “The ruleset is right…”; a successful change is confirmed; a batch import gives one dialog. Example: a New Age: Arcanum report opened in a game set up as New Origins.

1. A report opens and names things the ruleset doesn’t define

A dialog over the map. The list starts on the game’s current ruleset, so Change ruleset is dimmed until another is chosen. Focus starts on the list; Escape and × act as Close.
