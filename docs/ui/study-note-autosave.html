The hex notes stay as they are

The mage note was written as the twin of the hex note editor, which keeps its Save and Cancel. Navigator's decision, 2026‑09‑08: they are not the same shape. A hex note is added to and removed from a list, so its editor is a form that opens and closes and a Cancel means something there; the mage note is one field that is always on screen and belongs to one mage. The pair is split on purpose.
