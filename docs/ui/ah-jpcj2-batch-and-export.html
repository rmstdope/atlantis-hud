ah-jpcj.2 — the batch summary, and refusing an export nobody could import

The two halves left over from ah-jpcj.1, which is already being built. The decisions were taken in round 2 and round 3 — a map export in a batch is added and counted on its own line (B1), and an export from a report with no faction or no date is refused at the export dialog (E9). What was never written down is the exact wording in the cases the two mockups did not draw, and that is all this page asks about.

Found while planning this, and worth knowing before you answer. Today a map export dropped into a batch is judged by judgeReportUsable like any other report — so one from your own faction takes the batch's import path and commits as your turn, replacing the stored report with a file that has no orders template, no events and no units. Only single-type factions can reach that today; ah-jpcj.1's header fix hands it to everybody. That is what makes this bead a P0 rather than a tidy-up.
Chosen (navigator, 2026-08-29): B, D and F. The headline gets its own sentence rather than a third clause; a map export that added nothing says so in words rather than showing a nought; and the export dialog states only why, dropping E9's "Export is unavailable for this turn" tail, because the greyed button already says that and the tail said turn twice in two senses. Each rejected variant is drawn beside the chosen one below.

Q2 A map export in the batch that added nothing new

Every hex in the file was already on your map — a second copy of an ally's file, or one you have already taken. It is not a failure and it is not a skip.

Q3 The export dialog, refusing a file nobody could import

E9 settled the no-faction case and its sentence, and that the button goes away rather than the save failing later. The date case needs the same treatment and was never drawn. Both are shown at the dialog's real 26rem width, with the existing area line and switch block above them.

Decided without asking, being reuse rather than new words. A map export in a batch that is itself unimportable — no faction, no turn, no hexes — is skipped with the same sentence the single-file path already uses, on the batch's existing skip line: bad-map.txt — skipped: the map export does not say which turn it was written on. And a batch with no faction of the player's own to import into keeps the reason it gives today for every other file.
