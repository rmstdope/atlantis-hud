A door into the game data — proposals (bead ah-u44o)

Your words: “It should be possible to bring up the game data both using keyboard shortcut and through the palette.” Today both routes start from a specific thing — you search for “Mining”, or you click the word somewhere. There is no way in if you do not already know the name.

Good news first: the cold-open state already exists in the code. openGameDataDialog(index, null) already handles being opened with nothing named — it falls back to the first category and selects its first entry. Nothing has ever called it with null. So this bead is a door, not a new room: the dialog behind it is the one ah-5jkt.1 already built.

§1  Which key taken: ⌘K palette, ⌘/ help, ⌥↓↑ units, F8 problems

A F2

  • No browser claims it, on any platform — the only option here of which that is simply true.
  • Sits with F8, which this app already owns, so the function-key row becomes “the app’s own keys”.
  • Same chord on macOS and Windows; nothing to explain twice.
  • Not mnemonic. Nothing about F2 says “reference”.
  • Awkward on a Mac laptop, where the function row wants fn.

B ⌘⇧K / Ctrl+Shift+K

  • Reads as a sibling of the palette — ⌘K finds a thing, ⌘⇧K browses everything. The nicest to remember of the three.
  • Free on macOS.
  • Firefox uses Ctrl+Shift+K for its Web Console on Windows and Linux. This app ships as a web app, so that is a real collision for some players — we can preventDefault, but only once focus is in our page.

C F1

  • The oldest convention there is for “reference”.
  • No modifier, no platform split.
  • This app already has a help key — ⌘/ shows how to get around. Two help-shaped keys meaning different things is worse than one unmemorable key.

§3  What the palette entry says it will sit among ~270 dictionary entries, so its wording is how you find it

G “Browse game data”

game|
Browse game dataaction
Gateway to plain [1] · plain (9,22)structure
  • The verb says it opens something to look around in, not a page about “game data”.
  • Matches game, data and browse.

H “Game data”

game|
Game dataaction
  • Shortest, and matches what the dialog is called elsewhere.
  • Reads like a dictionary entry rather than a command, sitting among 270 that are.

I “Open the rules reference”

rul|
Open the rules referenceaction
  • “Rules” is what a player would call it, and it is what the data is scraped from.
  • The app says “game data” everywhere else; a second name for one thing.
Whichever wording you pick, the entry is an action, so it also inherits the palette’s keybinding hint column — the chord from §1 will show beside it, and in the ⌘/ help overlay, automatically. Nothing extra to wire.
