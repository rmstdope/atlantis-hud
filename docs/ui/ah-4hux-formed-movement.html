ah‑4hux — a unit you FORM this month, walking away this month

You reported that a unit created by FORM and then given MOVE orders shows no destination on the units table and draws no path on the map. It does not, and I have found why: the forecast decides a formed unit's status before it looks at its movement orders, so new 1 is filed as “formed” and never traced; and the map's trace looks its unit up in the turn report, where a unit that does not exist yet cannot be found.

rules/form: the new unit starts “in the same region as the unit which formed it, and in the same structure if any”, and rules/sequenceofevents processes every FORM before movement — so it really does set out from its parent's hex, this month. Nothing about the game is in doubt here; what is open is what the two units panes say about it.

The example throughout. Hex plain (7,53). Unit 1922 Tax Collector holds 6 men and $540; its orders read:

unit 1922 form 1 move n n end give new 1 2 leaders give new 1 200 silv

So new 1 gains two leaders and 200 silver, and walks two hexes north to swamp (7,51). Today its row says only new, and the map is blank.

Round 3 — I mocked Q3b in a way the code cannot honestly deliver

You chose Q3b: draw the destination even for a formed unit that dissolves. I then checked the machinery and found my own mockup was lying. A row's → 1:7,51 does not mean “the last hex of the order” — it means where the unit stands when next month's report is written, which needs the unit's speed. Speed comes from the men and goods it carries, and a unit that dissolves is by definition one that gained nobody: rules/form, and the code agrees — a unit with no men has no stated speed at all. So the forecast cannot name a hex for it, and the honest row is → …, which is exactly what it already shows for any other unit whose speed it cannot state. The map line is unaffected: the hexes the order walks are known without knowing the speed, and it is drawn dotted the whole way, which is how the map already says “beyond what I can time”.

Round 1 recommendation (now chosen): O1 and D1. They are the two that change no existing rule — the departure arrow keeps meaning “leaving this hex”, the arrival row keeps meaning “will be standing here”, and new keeps meaning “this month creates it”. The formed-and-moving unit is then just a row that happens to be both, rather than a fourth case with rules of its own. They are also the cheapest: the forecast already draws both rows for anything with a destination, so the work is letting a formed unit have a destination.
