Show errors — Option A: go to the first error

Show errors closes the dialog and jumps straight to the first error in the orders — the same landing as the ‹ › problem buttons and F8 — with the broken order selected in its unit's orders.

1 · After pressing Show errors chosen

The first error in document order may be in another unit: the map selects that unit's hex and its orders open, exactly as an F8 step does. The position beside the problem buttons counts all problems, warnings too, so the player can keep stepping with › or F8.

2 · Rare: no error can be placed on an order line

A few errors belong to a hex rather than to an order line (for example an unknown building), and the problem buttons cannot land on them. When none of the errors can be landed on, Show errors falls back to the original agreement: the "to check" chip's panel opens on its Problems tab, where those hex errors are listed.
