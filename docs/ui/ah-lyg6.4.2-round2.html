ah-lyg6.4.2 — the confirmation and the Undo

Round one chose W3 (confirm, then offer Undo), X1 (a conflicting month-long order is replaced and named), Y1 (a missing block is made under that mage's own region banner) and N2 (the lines are annotated exactly as the tab shows them). Two things are still open: what the confirmation looks like, and what the Undo is worth once you have carried on working.

D — where the confirmation appears

The study planner is itself a dialog covering the whole window, so this cannot be the header's status line and it is not obvious it should be a second modal. The repository's own precedent is OrdersImportPrompt — "a box in the flow rather than a modal, so the map stays where the player left it while they decide".

D1 A box in the Orders tab, above the sections

The tab body scrolls down; the box takes the top of it. The text you are about to write is still on screen underneath, which is the thing you are confirming.

U — what the Undo is worth afterwards

The Undo restores the document as it was a moment before the write. But you may have closed the planner, selected a unit and typed three lines by hand before you press it — and restoring the document byte for byte would take those three lines with it.

U1 Offered until anything else changes the document

The Undo stands while the document is exactly what the write left. The first keystroke anywhere, or an import, or a restore, and it quietly goes.
Wrote study orders for 4 mages; 1 other order replaced. Undo
Wrote study orders for 4 mages; 1 other order replaced.
  • It can never destroy work — by construction there is none to destroy.
  • Cheap and exact: one saved string and one equality test.
  • Type one character and the way back is gone, with only the line greying to say so.

U2 Offered until the planner is closed

The Undo stands for as long as you are in the planner, whatever else has happened. Pressing it restores the whole document, and says so first.
Wrote study orders for 4 mages; 1 other order replaced. Undo
Undoing puts your orders back as they were before the write. Anything typed since will go with it.
KeepUndo the write
  • The way back is there when you notice the mistake, which is rarely instantly.
  • A second confirmation, on the button that exists to save you from a confirmation.
  • It can still lose typing, and the warning is the only thing stopping it.

U3 Undo only the lines it wrote

Each mage's block is put back individually, and only if it still reads exactly as the write left it. A block you have since edited is left alone and named.
Wrote study orders for 4 mages; 1 other order replaced. Undo
Put 3 mages back; Ereb (1234) was left alone, you have edited him since.
  • Never destroys anything and never expires — the strongest of the three.
  • The most work, and a partial undo is a state that has to be explained in a sentence every time.
