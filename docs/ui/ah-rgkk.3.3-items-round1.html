Q2 — one item can move several times. How do the causes read?

Porters’ month is eight movements over six items: grain alone was sold, and sent away. Same twelve lines above in each; only the block underneath differs.

  • Nothing is ever merged away: every order that moved a thing has its own line.
  • Reads in the month’s own order, so the popup tells the month as a story.
  • Eight sentences under twelve figures — the popup is now mostly prose, and a twenty-order unit is unreadable.
  • Nothing ties a sentence to its line but the item’s name.

  • One sentence per changed line, so the block can never be longer than the list above it.
  • The leading item name ties each sentence to its figure by eye.
  • A unit that bought the same thing at four prices gets one long, comma-heavy sentence that wraps to three lines — and the wrap is where the cost bites, not the count.
  • The month’s order survives only inside a sentence, not across the block.

  • The list stops being a scannable column of figures.
