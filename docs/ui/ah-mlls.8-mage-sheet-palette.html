Mage sheet in the palette — round 1

Today the palette offers "Export map" but not the mage sheet, which is only under the header's Export button. Choosing the new row does exactly what that menu item does: the palette closes and the save dialog opens for mages-<faction>-turn-<n>.txt. Four questions about what you see around it.

Chosen: 1A "Export mage sheet"; 2B greyed with a reason (refined in round 2, ah-mlls.8-mage-sheet-palette-2.html); 3B "no mages"; 4A a failed save behaves as the menu does today.

1 — What the row says

Shown with the palette open and "exp" typed.

A — recommended "Export mage sheet"

The same words as the Export menu item, beside "Export map", tagged action like every command.

exp|
Export mage sheetaction
Export mapaction
  • Matches the menu exactly - the industry habit (VS Code, Figma) is that a palette command carries the menu item's name.
  • Typing "ally" or "share" finds nothing.

B "Export mage sheet" + how many mages

Same words, plus the count of your mages that will go in the sheet.

exp|
Export mage sheet6 magesaction
Export mapaction
  • You see what you're about to send before the save dialog.
  • A number on a command row is new; no other action carries one.

C "Share mage sheet with allies"

Says what it is for rather than what it does.

sha|
Share mage sheet with alliesaction
  • Typing "share" or "allies" finds it.
  • Different words from the menu for the same thing; "exp" no longer finds it beside Export map.

2 — When the mage sheet can't be made

Without the game data loaded the app can't tell a mage from a woodcutter (the menu item is greyed out then). Shown with "exp" typed.

A — recommended Row not offered

The row is simply absent until it would work - as Export map is absent before a report is loaded.

exp|
Export mapaction
  • How the palette already treats every unavailable command; nothing to press that does nothing.
  • Someone looking for it doesn't learn why it isn't there.

B Row shown, greyed, with the reason

Visible but can't be chosen; the arrow keys skip it.

exp|
Export mapaction
Export mage sheetneeds the game dataaction
  • Says why, like the greyed menu item.
  • The only greyed-out row in the palette; a new kind of row to learn.

3 — When you have no mages this turn

The menu today still saves a sheet - with no units in it.

A Offered, saves an empty sheet

Exactly what the menu does.

exp|
Export mage sheetaction
Export mapaction
  • Same behaviour from both places.
  • You can send an ally a file with nothing in it without noticing.

B — recommended Offered, says "no mages"

Still works, but the row warns you first.

exp|
Export mage sheetno magesaction
Export mapaction
  • Warns before an empty file goes out, without hiding a command that exists.
  • The one action row that ever carries a remark (as an empty Army says "no units this turn").

C Not offered

Treated like the missing game data: nothing to export, no row.

exp|
Export mapaction
  • Can't make an empty sheet from the palette.
  • Palette and menu disagree - the menu still offers it.

4 — If saving fails

Rare: the sheet couldn't be written. A cancelled save stays silent either way.

A — recommended Same as the menu today

The menu's mage-sheet export shows no message on failure today. The palette does the same; fixing it for both is a separate piece of work.

map
  • Stays the size it was filed at; both doors behave the same.
  • A failed save goes unnoticed, from either place.

B A short message, from both places

A notice over the workspace until dismissed (Escape or ×).

map
Couldn't save the mage sheet. ×<the reason, as the system gives it>
  • You know it didn't go.
  • Changes the Export menu too, and adds a notice the app doesn't have elsewhere.
