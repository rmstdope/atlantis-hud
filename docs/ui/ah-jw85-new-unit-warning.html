Question 2 · What the Problems panel calls it

Every entry opens with who it is about. Reported units are named by their number. These are the same entry, three namings — and beside them, for scale, the entry the Scholar gets today.

N1 — the raw id, new-1. Exactly the string the row itself carries.

⚠2101short $140: this unit can have $60 and its studies spend $200

Question 3 · The message understates a unit that was given silver

Look at the message above: “this unit can have $0 and its purchases spend $100”. The new unit was given 100 and is buying 200 of Plainsmen. The message counts only what the unit holds in the report, so the gift is missing from both figures.

This is not new and not about FORM: a reported unit given silver by a neighbour gets the same understatement today. It is simply invisible until now, because it is worst when the unit holds nothing — which every new unit does.

M1 — leave the message as it is and fix it in a bead of its own, for every unit at once.
⚠new 1short $100: this unit can have $0 and its purchases spend $100
  • Keeps this bead about the column and the mark.
  • The panel says $0 on the same screen where the column says the unit was given 100.
M2 — fix it here, counting silver given to the unit into both figures.
⚠new 1short $100: this unit can have $100 and its purchases spend $200
  • The panel and the column agree, and every gift-receiving unit's message improves with it.
  • Changes a message on units that have nothing to do with FORM, inside a bead about FORM.

Chosen: C1 (both go to the forming unit), N2 (new 1) and M2 (the message counts silver the unit was given). The shipped message reads “and its orders spend $200” — spenders prints only orders or orders and upkeep.
