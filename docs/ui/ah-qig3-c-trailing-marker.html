ah-qig3 — a trailing marker beside the skills

A unit writing STUDY has its next-turn skills forecast drawn in the Skills popup, but the cell itself says nothing, so the forecast is only found by resting the pointer on it by accident. Every other previewed change marks its cell italic brass. This page is variant C of three; open all three before choosing.

The scene. Five own units in one hex. Braves (1487) writes STUDY COMBAT and nothing else touches its skills. Scouts (1502) both takes two men from another unit (which moves its figures this month) and writes STUDY OBSERVATION. Trappers (1774) only takes men — today’s brass mark, unchanged by this bead. Hunters (1901) writes STUDY MAGIC but is short of the fee, so the projection is doubted. Watch (1620) does nothing.

C — the skills text is left alone and a blue marker is appended

The cell’s text keeps whatever it already says — plain, or italic brass when this month moved it — and a small blue → COMB 2 is appended, naming the skill and the level the study lands on. This is the shape the row already uses for new and ← 1234 in the Unit cell. A doubted projection gets a trailing ?, the same mark the popup uses.

  • Says which skill and what level without hovering — the popup becomes the detail rather than the discovery.
  • Carries doubt onto the row: → FORC 2?.
  • The widest option. In a narrow Skills column the marker is what gets truncated away, which is the one thing that must not be lost.
  • A new idiom for this table: no other cell appends a projection to its own contents.
