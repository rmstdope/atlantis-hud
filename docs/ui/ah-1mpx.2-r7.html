U4 — when This hex lights in brass

Round 3 settled “stay, but say so”: clicking a hex while an Army is the source keeps the Army and marks This hex in brass with a ● and the new hex's count. What it did not settle is whether the mark is about having clicked, or simply about the two not matching.

Option A — brass whenever the source is not This hex recommended
This hex 9 ●
All my units 38
Armies
Northern Host 12
  • One rule, stated in one sentence, with no history in it: the mark means the table is not about the hex on the map, which is true from the moment you leave This hex.
  • Nothing to remember and nothing to reset — no “has the hex changed since…” state to get wrong when a turn loads or a game opens.
  • Brass from the instant you pick an Army, so the mark is on screen the whole time you work in one — and a permanent highlight is a weak signal.

  • Sitting on an Army with the map on a completely different hex looks calm, which is the state round 3 wanted made visible.
