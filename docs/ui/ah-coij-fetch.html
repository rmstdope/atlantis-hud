ah-coij — the sign-in goes away; the password is asked for each time

There is no signed-in state on a New Age world any more, on Arcanum or on Trident. Nothing is held between actions: each of Fetch and Send logs in with the faction number and password typed into its own dialog, does the one thing it was asked to do, and forgets the token. A reload, a game switch and a ruleset change all become uneventful, because there was never anything to lose.

The header chip that read Sign in to Arcanum, and the faction-name chip with its popover behind it, are replaced by one button that always says Fetch and always does the same thing.

The header

One button, one meaning, whether or not a report is loaded.

  • Still between Export and Send, and still absent on a game that is not played under a New Age world.
  • Send keeps its own button and its own dialog, unchanged except that it now always asks for the faction number as well as the password.

The Fetch dialog

Two fields and two choices. The dialog stays up while it works, so there is one place to watch and one place to stop, and it closes itself when the work is done.

READY a report is loaded

The faction number is prefilled from the report on screen and stays editable. This turn's report is selected every time the dialog opens; the choice is not remembered.

Nothing to prefill from, so the faction number is blank and the meta line drops its turn. Fetch stays off until both fields are filled — the rule the sign-in already had.

The password is cleared and takes focus back; the faction number and the choice are left as typed. There is no session ended notice, because there is no session to end.

The fields go away, the dialog does not. Cancel is in the same place throughout, and Escape does the same thing as pressing it.

WORKING one turn

A login and a download. Over quickly, and the dialog closes itself when the report has been read.

The Send dialog

Almost unchanged: it already asked for a password on every send. What changes is that the faction number is always asked for too, and that a refusal is now just a refusal.

SEND as it will be

Send orders to Arcanum

Merchant Guild (27) · turn 83 · atlantis-newage.com

Used for this send only. Nothing is written to this machine.

  • The confirm button always reads Send. Sign in and send described a state that no longer exists.
  • Every verdict sentence — saved, saved with errors, not saved, unreachable — is unchanged.

GONE what this deletes

  • The sign-in dialog, and every re-authentication path that put it back up mid-action.
  • The earlier-turns dialog and its per-turn list. The second radio replaces it; a single old turn can no longer be asked for on its own.
  • Sign out, and Nothing is stored: closing Atlantis HUD signs you out.
  • Your session has ended. Sign in again to continue. — a refusal mid-action is now an ordinary refusal, and the dialog you are already in says so.
  • The faction-name chip and its popover summary, Signed in to New Age: Arcanum as Merchant Guild (27).
  • Dropping a token when a game closes, a game is deleted, or a ruleset changes — there is no token to drop between one press and the next.
