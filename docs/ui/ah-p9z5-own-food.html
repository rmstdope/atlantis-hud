ah-p9z5 — a unit fed from its own food says nothing

"It is only the unit that do not possess the food, that states 'Faction food in this hex covers {n} of this unit's upkeep.'. The other unit, the Granary, does not state that."

Both units show 0 upkeep. The one that was fed by a neighbour explains itself; the one that supplied the food does not. So a player learns the rule from the unit that did not have the grain.

This is a gap in ah-7cdt's plan rather than a defect in its code. That plan stated the principle — "an Upkeep of 0 on a unit with six men reads as a defect until something says why" — and then applied it only to the faction pool. The same reasoning applies to a unit eating its own food, and that is the commoner case.

Chosen the note follows the rules' own payment order

Decided 2026-08-23: B, own food first — and the navigator's reason is better than the one this page argued for. The note order should mirror the order the game pays in, not a judgement about which fact is harder to discover:

1. Food items the unit owns, if set CONSUME UNIT or CONSUME FACTION
2. Food items from faction units in the same region, if set CONSUME FACTION
3. Silver in the unit's possession
4. Silver from other faction units in the same region
5. Food items in the unit's possession
6. Food items from faction units in the same region
7. Unclaimed silver
8. Silver from allied units in the same region
9. Food items from allied units in the same region

Own food is step 1 and faction food is step 2, so a unit fed from both says the step that actually fed it first. The accepted cost is that a unit already shipped changes what it says in the mixed case — it will now name its own food where it named the hex's.

The panel shows one note — the first row of a table that matches. A unit owing 60 with one grain of its own takes 50 from that and 10 from the pool, so both lines would apply. Today's table has the faction-food line and this bead adds a sibling; their order decides which a player sees.

Chosen the new line, verbatim

It sits beside Faction food in this hex covers {n} of this unit's upkeep., so it should read as its sibling.

#LineNote
2-iThis unit's own food covers {n} of its upkeep.Chosen. Closest mirror of the existing line — same shape, same order of ideas, with "own" doing the distinguishing work.
2-iiFood this unit carries covers {n} of its upkeep.Avoids "own", which the existing line does not use either; slightly longer.
2-iiiThis unit eats its own food, covering {n} of its upkeep.Says what happens rather than what is true. Warmer, and further from the sibling's voice.
Both lines stay behind the countUpkeep setting, as the existing one does: with the Upkeep row hidden there is nothing on show for either to explain.
