Orders panel — A — the rows leave room for the count

Every row in the list stops a little short of the right edge, so the count always sits in empty space. A message that would have run under the count wraps onto a second line inside its row instead. The count stays exactly where we agreed: the list's bottom-right corner.

Cost: every row is about 60px narrower whether or not the count is showing, so long messages wrap sooner — most noticeably in a narrow rail.
