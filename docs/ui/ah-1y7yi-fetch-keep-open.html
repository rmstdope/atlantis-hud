Fetching from New Age asks before it replaces

On a New Age world, a fetched newer turn asks "Keep turn N / Open turn N+1" before it replaces the turn on screen, the same as New Origins. It works the same whether you pressed Fetch in the header or the assistant asked for the report. Agreed 2026-11-16 over two rounds. Every string is quoted exactly as it will ship.

1 · A newer turn arrives

Once the report is in, the Fetch dialog stops showing its working line and asks the question instead. It stays open until you choose. The focus is on Keep, so Enter keeps what you have. Pressing Fetch in the header and the assistant asking for the report work exactly the same way.

Nothing is asked when nothing is on screen, when the report fetched is older than the turn on screen (it is stored for history, as today), or when it is another faction's report (the strip under the header asks, as today).
