ah-13o — Resizable split between the unit and orders panels

Chosen: Option B — the always-visible grip, for discoverability over minimal chrome. With it: the drag is clamped by panel minimums only (the 55% ceiling governs just the default), the split persists across reloads globally like panel collapse, Escape cancels a drag in flight, double-click resets to the default, and the handle is keyboard-focusable (arrow keys nudge by 1rem, accessible name "Resize orders panel", no tooltip). A window too short for the stored split clamps to fit without touching the stored preference. The full interview is recorded in bead ah-13o's design field.

The right rail today: the unit panel takes whatever the orders editor leaves, and the editor is pinned at a fixed height. This adds a drag handle on the boundary between them. Both variants below are live — drag them. The difference is only how the handle announces itself; the drag behaviour is identical. Minimums are enforced while dragging (editor 9rem, unit panel 6rem) — the handle flashes amber when you hit one. Double-click a handle to reset to the default split.
