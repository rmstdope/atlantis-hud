ah-g9sf.5 — in Trident, the builders take the materials first

In New Origins a month runs: workshops make things, then building happens, then the region's own resources are gathered. In New Age: Trident the order is different: building happens first, and then one single stretch in which workshops and gatherers all work together, settled in the order the units stand in the report. Sources: newage/trident rules/sequenceofevents, rules/sequenceofevents.

Atlantis HUD uses the New Origins order in every world. In a Trident game that hands one shared pile to the wrong unit first, so the amounts produced, the leftovers and any shortage all land in the wrong place.

Agreed: the numbers become correct and no new words appear anywhere. Nothing on screen names the rule, the order or the world; every sentence a player reads is one the HUD already says today, with the right figures in it. Chosen panels below are bordered in green.

Four The unit that meant to build with timber it cuts this month

Not a shared pile at all, and the sharpest edge of the change. In New Origins a unit can cut wood and spend it on a building in the same month, because the gatherers run before the building does. In Trident the building is settled first, so this month's timber is too late for it: the wood stays in hand and the work does not happen.
