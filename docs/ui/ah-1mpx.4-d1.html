ah-1mpx.4 — round 1: the drag, the bulk line and the right-click

Round 3 of the epic already settled the gestures — click picks one, Shift+click extends, Ctrl/Cmd+click toggles, Shift+↑/↓ extends from the keyboard, Ctrl/Cmd+A picks everything the filter is showing, Esc narrows back to the cursor row, changing the source clears the pick. Picked rows take a 15% wash; the cursor row keeps today's 25% and is the one that fills the Unit panel. None of that is reopened here.

What round 3 drew but never specified: what a drag actually shows and what it may be dropped on, how you take several units back out of an Army, where the pick's count lives, and whether the right-click menu is a real nested menu or the popover that already exists.

D4 — the right-click

Round 3 drew Add to army ▸ with a submenu. This application has no context menu anywhere — the only right-click in it recentres the map — so whatever is chosen here is the first one, and it is the shape every later one will copy.
