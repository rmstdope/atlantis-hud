ah-12h7 — Teaches… when nobody is eligible yet

Today the Teaches… row appears only once somebody in the teacher's hex already has a teachable month planned, so every pupil must be planned before the teacher can be opened at all. The player wants the other order: name the teacher first, then fill in who he teaches.

Chosen: the row is always offered, and with nobody tickable it commits in one click. No second step, whatever dim rows the list would have held. Rejected: opening the step on an empty or all-refused list so the reasons can be read first — three clicks for a cell that has nothing to choose in it. The one exception is a cell already holding a list the player ticked by hand, which always opens the step so that list is never silently discarded.

The scene: turn 26, Blackthorn (12,8). Six of Seven is a force shield 3 mage. Two and Three of Seven are in his hex with nothing planned; Four of Seven is elsewhere. Nobody is eligible. A live teach cell already resolves to TEACH nobody and picks pupils up as they are planned — all that was missing was a way in.
