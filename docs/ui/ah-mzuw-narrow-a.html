Orders panel, narrow rail — A — the warning flows like a sentence

Each warning reads as one line of text: the ▲, “line 4”, the order word and the message run on together and wrap back to the row’s left edge, like a sentence does. Nothing in the row has a fixed column any more, so however narrow the rail gets the text wraps before it reaches the count’s room.

Cost: a wrapped message no longer lines up under its own first word; its second line starts under the ▲. That is true at every rail width, not only the narrow ones.

Today, for reference

The orders panel at its smallest, the right rail dragged narrower. From about 266 px down, the warning's text runs under “1 more ↓” (dashed outline): at 202 px the word “short” is drawn over.
