What this costs, and what is assumed

  • The screen gets quieter and nothing else. A player who saw twelve wrong warnings yesterday sees none today and is given no reason why. That was the chosen trade.
  • An ENTER the game later refuses — the object is occupied by a faction that has not declared you Friendly (rules/enter) — makes all six turns silently optimistic, with nothing on the screen recording that a seat was assumed.
  • Turns 26–30 assume he stays put. There are orders for one month only, so where this month's orders leave him is where the planner holds him for every later column.
  • An ally's mages are unaffected. You hold no orders document for another faction, so their shelter is still read from the mage sheet exactly as today.
  • Every LEAVE runs before any ENTER (rules/enter: an ENTER issued from inside another object leaves it first). A block holding both ends inside, so such a mage is sheltered and no clause about leaving is ever shown for him.
