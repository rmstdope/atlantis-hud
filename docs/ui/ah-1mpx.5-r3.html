ah-1mpx.5 — round 3: the pin's life, focus, and the narrow window

Settled so far: one Other factions rail entry; the dossier popover keeps Attitude and Seen in and gains a line into the list; a faction strip above the table pins one faction exactly, by number; a foreign unit's Skills cell reads not disclosed; a hidden owner reads not shown and can be pinned like a faction.

What is left is everything the happy path hides — when the pin dies, where the keyboard goes, and what the strip does when the window is narrow. These are the questions whose absence would have the implementer guessing.

You pin Thane's Ring, then next month's report arrives. Four events could clear it; the question is which do. Leaving the source and pinning something else obviously clear it — the argument is about a turn load.

Decided without you, and why

  • Columns: the ten, plus Hex — the same set All my units gets, since both span hexes. No Seen (everything here is this turn) and no Remove.
  • Escape clears the pin when focus is inside the pane and no popover or name field is open. It does not change the source.
  • A collapsed units pane expands when the popover's line is clicked — the action is meaningless otherwise.
  • The Faction cell link and the “not shown” link are tabIndex={-1}, like every other control inside a row: the table is one tab stop per row.
  • Own units never appear here, and foreign units never appear in All my units. This hex keeps showing both, as always.
  • Nothing changes about picking or dragging. ah-1mpx.4 puts no ownership test on either.
  • Clicking a hex on the map while this is the source behaves as it does for any non-hex source: stay here, and light This hex in brass with the new count.
