Settled in round 1: the popup is headed “Braves (1487) — items” (unit, then column); a change is marked arrow and signed amount, e.g. 12 ▲ +4; moving sideways along a row swaps the popup’s contents in place with no second wait; and the whole-unit summary survives on the Name and Id cells. This page is the rest of it.

F — Keyboard, and what replaces title for a screen reader

Today the popup is mouse-only by design (byMouse: a finger has no hover to leave). The title attributes were the only non-visual route to this material, and this bead removes all nine of them. The table is one tab stop per row; ↑↓ move the cursor, ←→ are unclaimed and currently scroll a wide table sideways.

F1 — no new key; every cell carries its own hidden sentence
mouserest on a cell → the popup, as round 1 settled keyboardunchanged: ↑↓ move rows, ←→ still scroll screen readereach cell reads its figure and then its explanation, from an sr-only span — the pattern Move and Flags already use
Reads as: “Items, 12 SWOR 40 SILV 2 HORS. Sword 12, up 4, four bought at 60 silver each. Horse 2, down 1, one given to Scouts 1502.”
  • No habit changes, and no key is spent.
  • Strictly better than title, which many screen readers skip entirely.
  • A sighted keyboard user still cannot see the explanation without reaching for the mouse.
  • Every popup’s text is built for every visible row, whether or not anyone hovers.
F2 — ←→ become a cell cursor, and the popup follows it
mouserest on a cell → the popup, as round 1 settled →moves a cell cursor along the row; the popup opens on that cell at once, no delay ↑↓move rows as now, keeping the column — the popup follows down the column Esccloses the popup and drops the cell cursor (before its existing meanings)
  • One route for everybody: what the mouse can see, the keyboard can see.
  • The popup is role="dialog"-shaped material already; this gives it a real focus story.
  • ←→ stop scrolling a wide table sideways — a habit that exists today.
  • Escape gains a third meaning on a row (it already narrows a pick, then unpins a faction).
  • Materially bigger: a cell cursor is state the table does not have.
