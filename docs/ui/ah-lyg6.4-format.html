ah-lyg6.4 — what the exported study orders say

Three spellings of the same plan, and then the four cases the happy path hides. All of it is legal order text: rules/orders allows ; comments anywhere, and rules/orders_abbreviations allows FORC where the skill's full name would do. Turn 72, three own mages (Ereb 1234, Sable 1250, Vess 1263) and one ally.

The spelling of a faction's block

Same plan, three ways.

F1 Bare

One comment naming the faction and the turn, then nothing but orders.
; Study orders for turn 72 — Atlantis HUD

; Borg TNG (95) — your faction
UNIT 1234
  STUDY FORC 4
UNIT 1250
  TEACH 1234

; Creeping Death (17)
UNIT 4021
  STUDY PATT 3
  • Shortest thing to read and to paste.
  • An ally receiving UNIT 4021 / STUDY PATT 3 has to look up which mage that is and take on trust that it is the one they meant.

F2 Annotated

The same lines, with the mage's name and what the month buys written as comments the server ignores.
; Study orders for turn 72 — Atlantis HUD

; Borg TNG (95) — your faction
UNIT 1234              ; Ereb
  STUDY FORC 4          ; force 3 -> 4, taught by Sable
UNIT 1250              ; Sable
  TEACH 1234            ; teaches Ereb

; Creeping Death (17), from their sheet of turn 70
UNIT 4021              ; Thessaly
  STUDY PATT 3          ; pattern 2 -> 3
  • An ally can check it against their own report without opening ours.
  • The comments are where a caveat can be said at all — a stale sheet, a halved month.
  • Longer, and a second thing to keep true as the planner changes.

F3 A whole order file per faction

F2's block wrapped in the envelope rules/orders describes, so the recipient mails the file itself.
; Creeping Death (17) — study orders for turn 72, from Atlantis HUD
#ATLANTIS 17

UNIT 4021              ; Thessaly
  STUDY PATT 3          ; pattern 2 -> 3

#END
  • Nothing to assemble: the ally mails it as it stands.
  • And that is the danger. A file mailed as it stands is all of that faction's orders for the month — every unit not named in it does nothing. It also cannot carry their password, which rules/orders requires on the #ATLANTIS line when one is set.
  • One file per faction, so the export is several files rather than one.

The cases the happy path hides

These are the ones worth arguing over.

S1 A mage with nothing planned next turn

Vess has an empty queue, or his queue's next step is not until turn 74.
UNIT 1234              ; Ereb
  STUDY FORC 4
; Vess (1263) — nothing planned for this turn
  • A named silence: you can see he was considered and left out.
  • The alternative is to leave him out entirely and say nothing.

S2 A teach nobody can receive

Sable's students are all in another hex, or none of them is studying. The planner already warns about this on the Schedule.
UNIT 1250              ; Sable
  ; TEACH 1263 — Vess is in another hex; nothing to teach
  • The order is commented out rather than dropped, so a wrong plan is visible in the file.
  • The alternative is to write TEACH 1263 anyway and let the server refuse it — which is what the player asked for, and harmless.

S3 No allies, or no sheets yet

Only your own faction has mages.
; Study orders for turn 72 — Atlantis HUD

; Borg TNG (95) — your faction
UNIT 1234              ; Ereb
  STUDY FORC 4
  • One section, no heading for factions that are not there.

S4 Nothing planned at all

Mages exist, but no queue has a step for turn 72.
No mage has a plan for turn 72. Give a mage a study or a teach on the Schedule and his orders appear here.
  • Copy and Save are greyed while this stands, the way the Export menu greys an item it cannot fire.
