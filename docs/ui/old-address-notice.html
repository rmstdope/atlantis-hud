The closing-down dialog — every state

Chosen: a dialog at every launch, with one button that saves all games. It also opens over the “No game yet” screen. Escape and “Stay here for now” close it; “Go to the new address” opens the new address in a new tab and leaves this one open. Nothing is remembered: it opens again at the next launch.
