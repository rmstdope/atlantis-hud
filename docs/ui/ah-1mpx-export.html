Export to the battle simulator — two layouts, and the awkward states

You settled what it does: one or two Armies, and which side each is on is yours to choose. With one Army chosen, the other side goes out empty.

Facts from the simulator's own bundle (I read atlantis.pekle.lv/dist/main.*.js, not just the published example): the file must carry both an attackers and a defenders key or the loader refuses it with “Failed to parse the json, check json formatting!”. It accepts two shapes and sniffs which — its own (items:[{abbr,amount}], flat skills, flags:["behind"], combatSpell) and the raw Atlantis JSON-report shape. Each side may also carry an optional structure. Skill and item abbreviations it does not recognise are silently dropped — no warning; the unit simply arrives weaker.

A fact from the rules (rules/stealthobs, rules/reportformat): a report never discloses a foreign unit's skills — not one of the 1402 foreign unit lines across our fixtures carries a Skills: section. It does disclose their men, race and every large item. That is why this export is complete for your own units and never quite is for anyone else's.

X3 — what actually goes in the file

Northern Host attacking, nobody defending. Men are items (HDWA, LEAD) — which is how Atlantis and the simulator both model them — and the empty side still has to be present.

northern-host.json
{
  "attackers": {
    "units": [
      {
        "name": "Shieldwall (7954)",
        "skills": [
          { "abbr": "COMB", "level": 1 }
        ],
        "items": [
          { "abbr": "HDWA", "amount": 146 },
          { "abbr": "SWOR", "amount": 94 },
          { "abbr": "LARM", "amount": 57 }
        ],
        "flags": ["behind"]
      }
    ]
  },
  "defenders": { "units": [] }
}
Decisions bound into that
  • name is Name (number) — your choice, and what makes two units called “Scouts” tellable apart in the simulator.
  • skills carries every skill the unit has, not only the five combat ones; the simulator drops what it does not know.
  • items carries the unit's inventory, men included.
  • flags is ["behind"] or omitted — behind is the only flag the simulator reads.
  • combatSpell when the unit has one. Known for your own units only.
  • Always emit "skills" as an array, even when empty: it is one of the things the loader sniffs to tell the two formats apart.

Open question below: should silver go in at all? It is in your own units' reports, it plays no part in a battle, and it is never disclosed for a foreign unit — so including it makes your units and theirs look different in the simulator for no gain.
