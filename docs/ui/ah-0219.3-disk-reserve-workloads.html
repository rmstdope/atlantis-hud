Option A: keep a smaller non-Rust safety floor

The project declares an 8 GB full-build floor and a 2 GB non-Rust floor. The workflow selects the workload explicitly; an omitted workload preserves today's conservative full-build behavior.

Non-Rust work above its smaller floor

$ disk-preflight --workload non-rust
disk: 4.4 GB free, above the 2 GB floor for non-Rust work.

Non-Rust work below its smaller floor

$ disk-preflight --workload non-rust
disk: 1.7 GB free, below the 2 GB floor for non-Rust work.
A check that runs out of space can fail in a tool and read like a code error.
No declared reclaim can recover the missing 0.3 GB.

Rust work keeps the full reserve

$ disk-preflight --workload rust
disk: 5.7 GB free, below the 8 GB floor for Rust work.
A build that runs out of space fails inside the linker and reads like a code error.
To recover the missing 2.3 GB, run from /Users/you/project:
  cargo clean -p atlantis-hud-core

Old caller omits the workload

$ disk-preflight
disk: no workload supplied; using the 8 GB full-build floor.
disk: 5.7 GB free, below the 8 GB floor for Rust work.

Unknown workload

$ disk-preflight --workload docs
disk-preflight: unknown workload "docs"; expected rust or non-rust.

Narrow terminal

$ disk-preflight --workload non-rust
disk: 4.4 GB free, above the 2 GB floor for non-Rust work.
