The faction view — attitudes, allowances and unclaimed silver

Bead ah-vp3.2, the showing half of ah-vp3. Its sibling ah-vp3.1 is putting factionStatus and attitudes onto ReportHeaderInfo; this bead gives the player somewhere to read them, alongside the faction name, id, types and the unclaimed silver that has been parsed for months and never shown.

Everything drawn here is real, from tests/fixtures/reports/neworigins-3.0.0-g7-f95-t71.rep: Borg TNG (95), Magic 5, December Year 6, 6,038 unclaimed silver, mages and apprentices both at their ceiling — and 32 declared factions across five levels. That last number is what decides this design: whatever holds the view has to hold a list of thirty-odd names without becoming a wall.

Two questions: where the view lives, and how the attitudes are set out inside it.

Chosen. A, anchored off the faction name in the header, in the shape MergedFactionsPanel and TurnMessagesPanel already use — dismissed on Escape and on an outside press, with the attitude list scrolling inside it. The attitudes are set out as a line per level, the report's own shape, with a level the report prints as none. shown as declared-and-empty rather than omitted. Allowances are drawn as bars with the number beside them, lit brass at the ceiling, so “no room for another apprentice” reads without arithmetic. A faction whose report has been merged in is marked in brass with a ⌂ glyph, so the mark survives being read without colour.

Question 2How the attitudes are set out

Thirty-two factions at five levels, drawn three ways at the same width. A level the report prints as none. is shown as declared-and-empty, not omitted — the report states it, so the view can.

1A line per levelchosen

The report's own shape: one row per attitude, names run together as prose, level coloured from hostile red to allied green.

  • Compact, and reads exactly like the report it came from
  • Finding one faction means reading a paragraph

2A row per faction

One line each, sorted hostile to allied, with the attitude stated on every row. A merged faction is marked in place.

  • Scannable; one faction is one line, and ids line up
  • Thirty-two rows always scroll, whatever holds them

3Chips under a heading

Each level a heading with the factions as small chips beneath, wrapping to the width available.

  • Each name is a discrete target, ready to be clickable later
  • Chips waste width; the tallest of the three
