Send orders to the server — the dialog, in every state

The password is typed here and held only for the duration of the request: never written to settings, the game file, a keychain, a log line or an error message. The dialog is the only place it ever exists.

The request itself is settled: POST https://atlantis-pbem.com/game/upload-orders, multipart/form-data, fields factionId / password / orders. The faction number is read from the orders document's own #atlantis line, so nothing is typed twice.

KKeyboard

What I intend to specify unless you want it otherwise.
  • Opens with focus in the password field
  • Enter in the field sends, when the field is not empty
  • Escape closes and discards the typed password — and is ignored while a request is in flight
  • Focus returns to the control that opened it
  • No global shortcut for Send — it is not an every-minute action
  • Clicking the backdrop closes it, except while in flight
  • Matches useEscapeToDismiss, which every other dialog here uses
