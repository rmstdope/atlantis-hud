Study planner: reshape planned turns

Each turn header has controls for inserting a blank turn before it or removing it. The action applies to every mage: the selected column and every later column shift together.

Remove turn 74 for every mage?

Turn 75 and every later planned turn will move one turn earlier for every mage. This cannot be undone here.

Inserting has the matching confirmation: “Insert an empty turn before 74 for every mage?” The final visible turn is removed, so the schedule always shows the same number of future turns. Escape or Cancel closes the dialog without changing the schedule. Keyboard focus moves to the dialog when it opens and returns to the header control that opened it. On a narrow window, the schedule scrolls sideways as one unit.
