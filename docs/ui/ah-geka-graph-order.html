Whole graph — where each skill sits in its tier

The chosen design for ah-geka, settled with the navigator over three rounds. Real data from the shipped config/public/ruleset.json: 70 magic skills, tiers of 4 / 15 / 38 / 11 / 2, 102 prerequisite lines. Which tier a skill is in does not change; only where it sits inside that tier.

Every picture below is the whole drawing at its real world size, 1366 × 1095.

  • Every one of the 70 lineages in the shipped ruleset now fits the graph dialog at a zoom where the skill names can be read. Ten of them did not.
  • Summon balrog — the example this came from — runs across 429px instead of 783px.
  • The up-and-down carried by the 102 prerequisite lines falls from 31,401px to 11,104px.
  • The drawing is 1366 × 1095 world units — five pixels shorter than it is today, and the same width, so the dialog and the opening fit are untouched.
  • A column no longer reads alphabetically, so a skill is found by following a line or by switching to Branches.
  • The smaller columns carry holes; the widest is 313px.
