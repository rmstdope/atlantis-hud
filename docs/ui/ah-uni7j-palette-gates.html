Today a gate can only be found by spotting it on the map. These drawings put every gate you know of — including ones only an earlier report showed — into the search box (Ctrl/Cmd+K). Choosing one centres the map on its hex and selects it, so the Region pane shows the gate. Four questions below; each has a recommended answer. Gate numbers say nothing about where a gate is (data/GATE), so the place is always shown beside the number.
