Game data — the All tab F2 opens on

The agreed design: an All tab, far left, listing all 325 entries A–Z, each row marked with its kind. F2 opens on it. Wording: tab “All 325”, filter “Filter everything…”, no-match line “Nothing matches “…”.”, kind words Skill, Man, Mount, Ship, Monster, Equipment, Building (and Terrain once that tab exists).

1 · The All list

The All list — A · one alphabetical list, every row says what it is

Press F2: the dialog opens on All, far left. Every skill, man, mount, ship, monster, piece of equipment and building — 325 in this ruleset — in one A–Z list. Each row carries a small dim word saying what kind of thing it is. This is how a combined search usually looks (a launcher, an "everything" search).

2 · Following a link from All

Picking from All — A · you stay on All

You are on All, read mining, and press its link to mithril. The All tab stays lit and the All list scrolls to mithril. Choosing any row in the list behaves the same. “← Back to mining” works as today.

After following mining → mithril

Still on All; the list keeps whatever you had typed into the filter, unless mithril is hidden by it — then the filter clears so the lit row is visible.
