An order the game refuses — chosen design

A refused STUDY or CAST shows what the game leaves: no fee, no materials taken, nothing red. The refused cost is struck through with its reason, and the cell carries an amber ⚠. This replaces the red display agreed on 16 October. Agreed 2026-10-17: Q1 A, Q2 A, Q3 A, Q4 A, Q5 A, Q6 A.
