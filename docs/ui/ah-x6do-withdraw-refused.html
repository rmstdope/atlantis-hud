ah-x6do — a WITHDRAW the game will refuse

rules/withdraw: “Use unclaimed funds to acquire basic items that you need. If you do not have sufficient unclaimed, or if you try withdraw any other than a basic item, an error will be given.”

The catalogue says which items are basic by carrying a withdrawal price at all. Silver carries none — silver is claimed with CLAIM, not withdrawn — and neither does mithril. So WITHDRAW 500 SILV is an order the game refuses outright.

What the preview does today. The silver balance, the shortfall checks and the SILVER column already know the withdrawal brings nothing — that was settled and tested. But the ITEMS column is credited anyway, unconditionally, so it shows the unit 500 silver richer than every other surface believes it to be. That half is a plain defect and is being fixed either way.
