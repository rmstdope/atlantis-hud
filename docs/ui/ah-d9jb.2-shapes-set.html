Agreed — the Shapes texture set

A second entry, Shapes, joins Standard in the Texture set picker. It uses Standard's colours and adds one large shape per biome. Changes from the first exploration: mountain has darker rock with small snow tips, so it stands clear of tundra, and ocean has no wave marks, only broad deep and shallow patches. Hexes are turned like today while "Rotate biome textures" is on. Try it: switch between Standard and Shapes, untick Biome textures or Rotate, and try greyscale.
