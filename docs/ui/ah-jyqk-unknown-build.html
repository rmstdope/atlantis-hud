1 · The wording of the unknown-name error

P"there is no building or ship called …"

✕7675BUILD: there is no building or ship called Galeon — did you mean Galleon?
  • A full sentence, reads aloud
  • The longest

Q"unknown building or ship …"

✕7675BUILD: unknown building or ship Galeon — did you mean Galleon?
  • Same shape as today's "unknown order WROK"
  • Terser; the name floats at the end without quotes

R"no such building or ship '…'"

✕7675BUILD: no such building or ship 'Galeon' — did you mean Galleon?
  • Short, and the typed name is set off in quotes
  • Same shape as today's "no such direction 'nw2'"

2 · How the name is spelled back to you

Typed BUILD "ice cave" or BUILD RUIN. For an unknown name there is nothing to correct it to, so it is always shown as typed.

SThe game's own spelling

✕9812BUILD: an Ice Cave cannot be built by players
✕7227BUILD: a Ruin cannot be built by players
  • Matches how the other BUILD warnings name structures ("cannot build a Mine")

TExactly as typed

✕9812BUILD: an ice cave cannot be built by players
✕7227BUILD: a RUIN cannot be built by players
  • You see your own line echoed
  • Shouting capitals mid-sentence

3 · What a suggestion can point at

Typed BUILD Rin. The closest real name is Ruin, which players cannot build.

UOnly things you could build

✕7227BUILD: there is no building or ship called Rin
  • Never suggests a fix that is itself an error
  • A real typo of Ruin gets no hint

VAny name the game has

✕7227BUILD: there is no building or ship called Rin — did you mean Ruin?
  • Always the nearest spelling
  • Following the hint swaps one error for another
