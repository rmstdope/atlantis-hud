ah-5gk7 — what the editor offers after NAME once the synonyms parse

rules/name documents four targets: NAME UNIT, NAME FACTION, NAME OBJECT, NAME CITY. The engine also accepts BUILDING, SHIP, STRUCTURE as spellings of OBJECT, and VILLAGE, TOWN as spellings of CITY. Today the HUD marks all five invalid, so a perfectly good order is red and contributes nothing to the preview.

All three shapes below fix that identically — every one of the nine spellings parses, and the intent, the ledger and the preview are the same whichever was typed. The only difference is what the completion menu offers after you type NAME , and what the diagnostic names when the word is wrong. Each shape is shown against the same three moments.

Precedent worth knowing before you choose: DESCRIBE already offers all five of UNIT SHIP BUILDING OBJECT STRUCTURE in the menu today — synonyms and all, unlabelled. That is shape C.
