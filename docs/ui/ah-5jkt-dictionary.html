The game data dictionary — browse by type, land on a thing

One dialog: pick a type on the left of the header, see every entry of that type in the list, read the chosen one on the right. Opened from the palette or (in ah-5jkt.2) by clicking a skill or item named in a pane, in which case it opens already on that entry, with its type selected.

Real counts from the shipped ruleset.json: 96 skills (70 of them magic), 171 items — 86 equipment, 58 monsters, 14 men, 9 ships, 4 mounts — and 10 buildings, all fortifications. Missing categories are tracked separately as ah-3cj4.

The open question this page is really asking: how the types are divided. "Items" as one list of 171 is a long scroll; split by kind it is five short ones.
