ah-lbd9.3 — Option B: a Fetch button and a dialog

The same job as Option A, in the shape the rest of the header already uses for an action that reaches the network: Send is a button that opens a dialog, and in B so is Fetch. The dialog tells you what turn the world is on and what turn you have before anything is replaced, and every failure is answered where you are standing rather than in the status bar. Compare with Option A, where fetching is an item in the world popover and runs with no dialog at all.

Already decided and not being reopened: credentials are never stored; New Age is desktop only; there is no refresh endpoint, so an expired token means signing in again; and when a session runs out, the dialog you are already in asks for it (E1).

Not chosen (2026-09-04). Kept as the record of what was weighed: a sixth header control that is disabled whenever you are signed out, and an extra round trip on every open, bought a turn-number preview nobody asked for. Option A is ah-lbd9.3-fetch-a.html.

1 · Where it lives

A sixth control in the header’s right-hand group: Import · Export · New Age · Fetch · Send · ⚙. It is shown only for a New Age game on the desktop build, and is off until you are signed in.

signed inFetch is live

ImportExport ▾ Merchant Guild ▾FetchSend⚙

Fetch sits between the world chip and Send, so the group reads as who I am · what I get · what I send.

signed outFetch is off

ImportExport ▾ Sign in to ArcanumFetchSend⚙

Disabled with a hover reason — Sign in to Arcanum first. — the way Send is disabled with a reason today. The cost of B is right here: a control that is visible and does nothing most of the time.

4 · When you already have a report loaded

Whichever option is chosen, a fetched report is handed to exactly the same routing a dropped file goes through: newer or same-turn loads, an older one is stored for turn comparison and does not take the screen, and a report naming a different faction raises the question it already raises.

the usual caseNewer turn, your faction

Fetched turn 83 · 42 regions · 118 units

Saved orders always beat the report’s template, so nothing you have written is lost — that rule is not new and is not being changed.

rareOlder than what you have

turn 81 stored for comparison; turn 83 stays on screen
