ah-lbd9.3 — Option A: fetch from the world popover

Today a New Age turn report reaches Atlantis HUD only because you downloaded it from the web site and dropped the file on the window. Signed in (ah-lbd9.2), the HUD can fetch it itself. This page is one of two shapes for the control that does it. In A there is no new header button: fetching is an item inside the world popover you already have, it runs with no dialog, and the result lands in the ordinary status line exactly as a dropped file's does. Compare with Option B, where fetching is its own header button and opens a dialog first.

Already decided and not being reopened: credentials are never stored; New Age is desktop only; there is no refresh endpoint, so an expired token means signing in again; and when a session runs out, the surface you are already in asks for it (E1) rather than sending you back to the header.

Chosen (2026-09-04): A — the popover item, no dialog on the happy path; T1 — this turn only; the fetched report goes through exactly the same routing a dropped file does; and an expired session is asked for in a small dialog whose button reads Sign in and fetch. Option B is ah-lbd9.3-fetch-b.html.

4 · When the session has run out

The one place a dialog appears. There is no refresh endpoint, so the token simply stops working — and E1 says the surface you are in asks for it rather than sending you back to the header.

E1Sign in and it carries on

Fetch this turn’s report
atlantis-newage.com · New Age: Arcanum
Your session has ended. Sign in again to continue.
Kept only while the app is open. Nothing is written to this machine.
CancelSign in and fetch

The same two fields ah-lbd9.2 exported for this. Signing in here fetches straight away — you never have to ask for the report a second time.

and if the world is simply unreachable

could not fetch the report: could not reach atlantis-newage.com. Nothing was sent.

No dialog: nothing about your session is in doubt, so there is nothing to retype. The same sentence the sign-in already uses for an unreachable world.

5 · One turn, or a list of them?

The world can also list the turns it still holds. This is a separate question from A vs B — both shapes can carry either answer.

T1This turn only

One item, one call, one sentence to explain. An older turn is still reachable the way it is today: download it from the site and drop it in.

Signed in to New Age: Arcanum as Merchant Guild (27). Nothing is stored: closing Atlantis HUD signs you out.

T2This turn, or an earlier one

A second item opens a list of the turns the world still holds. An earlier one is stored for turn comparison rather than shown, by the rule in section 3. Costs a second endpoint, a list state, and its own empty and failure sentences.

Signed in to New Age: Arcanum as Merchant Guild (27). Nothing is stored: closing Atlantis HUD signs you out.
