Agreed — the Painted texture set

The Texture set picker gains Painted, after Standard (and after the procedural set once that arrives). The 17 painted pictures are stretched once over each hex. With “Rotate biome textures” on, each painted hex is turned by a sixth of a turn (0°, 60°, … 300°). With “Animate water textures” on, the painted sea slides like today’s water, mirrored where it wraps. The first time Painted is chosen, the map keeps Standard until all 17 pictures are ready, then changes at once; a picture that never arrives leaves its biome in flat colour, with nothing said. Untick Biome textures and the map uses the flat colours as before. Try it: press the button above the map, switch sets, untick the switches.
