ah-1tyi — completing what BUILD can name

Until now, after BUILD the popup offered only HELP and COMPLETE; the building or ship name was the player's to remember and spell, which is how CAxxxRAVANSERAI reaches an orders file. Agreed with the navigator on 2026-09-13 over two rounds of drawings.

Chosen. After BUILD the popup offers every building and ship a player can build in the game world being played (structures the game data marks "cannot be built by players" are left out). One list: HELP and COMPLETE first, then the names alphabetically, each with a quiet building or ship on its right. Names read in the list as the game data spells them, without quotes. Picking one writes it in the game data's spelling — in double quotes if it contains a space (BUILD "Timber Yard"), bare otherwise (BUILD Caravanserai) — followed by a space. Typed letters match the start of the name only, in any capitals.
