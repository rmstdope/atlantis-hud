Warning: BUILD without the skill for it

A unit ordered to BUILD a structure it lacks the skill for spends its month for nothing. The same class of wasted month as ah-vkut and ah-dwk6, and now checkable, because ah-bwly.1 puts the requirement in the ruleset.

What the data says, for the cases below: a Mine needs mining at 3; a Tower needs building at 1; a Citadel needs building at 3. Thirty-six of the fifty-eight structures carry a requirement; the rest say nothing, and the check stays silent for those.

Existing warnings are phrased as a verb phrase completing the unit's name — "Miners (7227) is in no structure to build in", "has no order that spends the month". All three options below keep that shape.

1 · How the warning reads

Drawn as the region pane draws a problem. Two rows each: a unit with the skill but too low a level, and a unit without the skill at all.

AWhat is needed, and what it has

States the requirement and the shortfall in one line.
Problems — plain (16,0)
▲Miners (7227) cannot build a Mine: needs mining 3, has mining 1
▲Builders (7675) cannot build a Citadel: needs building 3, has no building
  • Everything you need to act on, in one line: the structure, the skill, the gap
  • Reads the same whether the shortfall is one level or the whole skill
  • The longest of the three, in a list that can already be long

BJust what is needed

States the requirement; leaves you to see the unit's own skills in the pane.
Problems — plain (16,0)
▲Miners (7227) needs mining 3 to build a Mine
▲Builders (7675) needs building 3 to build a Citadel
  • Short, and says the one thing that would fix it
  • Reads naturally aloud
  • Does not say how far short the unit is, so a level-2 unit and a level-0 unit look identical

CTwo different messages

A unit with none of the skill and a unit one level short are arguably different mistakes: one is the wrong unit for the job, the other is a unit that needs a month of study.
Problems — plain (16,0)
▲Miners (7227) has mining 1, and a Mine needs 3
▲Builders (7675) has no building skill, which a Citadel needs
  • Each case reads as what it actually is
  • Two strings and two branches for one check, and both still say the same thing
  • Two shapes in one problem list reads as two different warnings

2 · Does a helper need the skill too?

BUILD HELP 7227 contributes a unit's labour to somebody else's building work. Whether the helper needs the skill is a rules question the scraped data does not answer, and it decides whether this check fires on helpers at all.

Problems — plain (16,0)
▲Labourers (9812) needs building 1 to help build a Tower
▲Labourers (9812) — or no warning at all —
  • The existing build-help-not-building check already covers a helper whose target is not building
  • If helpers do need the skill, a silent check here lets a wasted month through; if they do not, warning is simply wrong

3 · Where the toggle sits

Settings → Warnings already has a Building group holding the three existing BUILD checks. This joins it as a fourth.

Building
Building what is built
A BUILD order on a structure the report already shows as finished.
Building outside a structure
A bare BUILD or BUILD COMPLETE by a unit that is in no structure.
Helping a unit that is not building
A BUILD HELP naming a unit with no BUILD order of its own.
Building without the skill
A BUILD order for a structure the unit has not the skill or level to build.
  • New checks default to on; only the broad unguarded-hex check ships off
