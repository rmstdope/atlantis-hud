One new column, Flags, showing every flag the report prints for a unit as a run of letters with nothing between them. Only the Unit, Men and Flags columns are drawn here; the pane's other eight are cut away so the comparison is about the letters.

The alphabet — the same in every variant

Twelve flags a New Origins report can print for a unit. Each gets one letter, chosen to be the initial of its order word wherever that is free, and something mnemonic where two orders collide (AVOID/AUTOTAX, NOAID/NOCROSS, SHARE/SPOILS, and the two forms of CONSUME).

A avoiding AVOID 1
B behind BEHIND 1
G on guard GUARD 1
H holding HOLD 1
N receiving no aid NOAID 1
X won't cross water NOCROSS 1
R revealing faction REVEAL FACTION
S sharing SHARE 1
T taxing AUTOTAX 1
C consuming unit's food CONSUME UNIT
F consuming faction's food CONSUME FACTION
P battle spoils SPOILS <mode>

The letters are always drawn in that fixed order — A B G H N X R S T C F P — never in the order the report happened to print them, so the same set of flags always reads as the same run and two rows can be compared at a glance.

2 — Battle spoils: one letter, or none at all

SPOILS is not an on/off flag: it has seven settings, and the report prints the one in force (weightless battle spoils, riding battle spoils, and so on). One letter can say a spoils setting is in force but not which. In this fixture 179 of the faction's unit lines carry one.

2-in — P for any spoils setting

UnitFlags
*Woodsmen (9431)ABNRP
*Lone Rider (12903)ABNRSP
*Lumberjacks (11991)ABNRS
  • The column is complete: every flag the report printed is represented.
  • P is on most rows and says the same thing on all of them; which mode is only in the hover text.

2-out — spoils left out of the column

  • Two units that differ only in their spoils setting now look identical in the column; the setting is visible only in the unit panel and the hover text.

4 — The hover text (not in question, shown for completeness)

Hovering the cell gives the flags in the report's own words, in the same ·-joined form the unit detail panel already uses — so the letters never have to be memorised. This is a plain title attribute, the same mechanism every other cell in the pane uses.
