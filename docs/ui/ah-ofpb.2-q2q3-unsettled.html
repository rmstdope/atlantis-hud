Q2 & Q3 — the builds the column cannot settle

Q1 is about the ordinary builder: alone, inside its own structure, with one material and plenty of it. This page is about the six rows where that breaks down. Two questions, and they are independent — answer them separately.

Six units, one hex. Each is ten men with the skill its order wants at level 3, so each could do 30 units of work.

unit 5551 ; Miners, 10 humans, 120 wood, 120 stone, mining 3 build Mine ; a Mine is built from 10 "wood or stone" - it holds both unit 5552 ; Quarrymen, 10 humans, 120 wood, quarrying 3 build Quarry ; a Quarry is "wood or stone" too - but it holds only wood unit 5553 ; Hodmen, 10 humans, 120 wood, building 3 build help 5541 ; 5541 is our unit, in this hex, working on Stockade [4] unit 5554 ; Shipwrights, 10 humans, 120 wood, unfinished Cog [COG] (needs 15), shipbuilding 3 build ; a bare BUILD works on an unfinished ship the unit possesses unit 5555 ; Recruits, 10 humans, 120 wood, in Stockade [4] build ; no building skill at all, so no work gets done unit 5556 ; Labourers, 10 humans, 120 wood, building 3, in Stockade [7] (needs 6) build ; could do 30 work; so could 5543 next to it; the Stockade wants 6 unit 5543 ; Finishers, 10 humans, 120 wood, building 3, same Stockade [7] build ; the rules never say which of the two spends its wood first

Units 5556 and 5543 are one question, not two. Each on its own is exactly resolvable: ten men at building 3, thirty units of work, six wanted. Together they are not. rules/sequenceofevents gives the order of the phases and never the order between units inside one, so which of the two spends wood on those last six units of work — and whether the other spends any at all — cannot be derived from the report. This is the one thing on this page the rules genuinely do not settle.

Unit 5555 is already warned about elsewhere by build-without-skill, so this question is only about what its ITEMS cell does.

Q2 — a structure built from “wood or stone”

Ten of the game’s structures — Mine, Farm, Ranch, Timber Yard, Inn, Quarry, Trapping Hut, Stables, Oasis, Caravanserai — may be built from either. The data page states both and does not say which the engine takes, so a unit holding both is a genuine fork. Only units 5551 and 5552 differ between these three; the rest of each table is Q3’s.

Q3 — helping, ships, and a unit that does no work

Four more rows. BUILD HELP puts the helper’s own material into somebody else’s structure. A bare BUILD by a unit holding an unfinished ship works on the ship, not on the region — and the ship is an item in the unit’s own list, unfinished Cog [COG] (needs 15), whose remaining need the report prints but the application does not model. Unit 5555 does no work at all. Units 5556 and 5543 are both working on a Stockade that wants only six more units of work, and nothing says which of them gets to spend it.

Q4 — two units finishing one structure between them

Stockade [7] wants six more units of work. Units 5543 and 5556 are both inside it, both able to do thirty. The engine will spend six wood in total, from one of them or split between them; the rules do not say which, and the report cannot tell us. Every other case on this page has one right answer — this one has three plausible ones.

P1 — count each unit alone, as if it were the only builder.recommended

IDNAMEORDERITEMS
*5543Finishersbuild10 HUMN, 114 WOOD
*5556Labourersbuild10 HUMN, 114 WOOD
hover on either ITEMS cellwas: 10 HUMN, 120 WOOD Spends 6 WOOD on Building 7 this month. Its men could do 30 units of work; the structure needs 6 more.
  • One rule, and it is the rule the whole column already runs on: every figure is what this unit’s orders do, measured against what the report printed. A PRODUCE is already counted this way when two units draw on the same market.
  • Each row is right about the unit whose row it is, which is what a per-unit column is for.
  • The two rows together claim twelve wood will be spent where six will be. A player adding up their stone before a big build gets a figure that is too high.

P2 — count them in order and let the first take what it can.

IDNAMEORDERITEMS
*5543Finishersbuild10 HUMN, 114 WOOD
*5556Labourersbuild10 HUMN, 120 WOOD
  • The totals across the hex come out right: six wood, once.
  • Invents an order the rules do not state. Unit 5556 is shown doing nothing, and it may well be the one the engine picks.
  • The row a player is looking at can change because of a unit further down the list, which no other column does.

P3 — mark both, since neither can be settled.

IDNAMEORDERITEMS
*5543Finishersbuild10 HUMN, 120 WOOD + ?
*5556Labourersbuild10 HUMN, 120 WOOD + ?
  • Honest: this is the one case the rules really do leave open.
  • The mark keeps meaning exactly what it means everywhere else.
  • Only bites when the structure’s remaining need is smaller than what the builders could do between them — which is the last month of every build, and the month a player looks hardest.
  • Two units quarrying a Citadel that needs 800 are never in each other’s way, so the rule has to test the total against the need before deciding, which is a rule with a condition in it.
