ah-awcm — money a unit TAKES — round 2

The Silver column ignores TAKE entirely, so a unit ordered TAKE FROM 17 100 SILV is shown $100 less than it will hold. The fix puts that money in the figure. The question is what, if anything, the hover says about it.

Today one sentence explains money arriving from elsewhere: Includes $25 given by Scout (101) in this hex. Folding a TAKE into it would say “given by” for money the unit took, which is the wrong word — a unit taking is not being given.

SETTLED Round 1 decisions

  • B — a taking gets its own sentence; the gift sentence is untouched.
  • TAKE ALL — the column refuses to price it rather than using a stale holding.
  • Source not in the report — the column does not count it (the ledger still does, deliberately: generous so it never warns falsely, exact so it never shows money that is not there).
