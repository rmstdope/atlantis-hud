The sentence for the three classes that are still unknowable

After this bead, GIVE 901 ALL MAGIC is the only shape of order left that the SILVER column cannot price — that, its two siblings ADVANCED and SPECIAL, and GIVE 901 UNIT. Today one sentence covers all fifteen classes. It will now cover three, and it does not say which. The question is whether it should.

What happens is already settled and is not being reopened: the cell shows ?, the hex's combat-ready sum goes unanswerable and the pillage warning goes quiet — decided in ah-dxfd.2.

OPTION A — leave the sentence exactly as it is
SILVER cell This unit is giving away a whole class of goods, which cannot be counted.
  • No string changes anywhere; nothing to translate, test or keep in step.
  • Still true of every case it now fires for, GIVE 901 UNIT included.
  • It reads as though any class defeats the application, which stopped being true the day this bead ships — a player who saw it for ALL WEAPONS last month will not try again.
  • Gives the player nothing to act on: they cannot tell that naming the items outright would work.

and for GIVE 901 UNIT, which has no class to name — the old sentence, kept
This unit is giving away a whole class of goods, which cannot be counted.
  • Names the one thing the player can act on: this class, not classes in general.
  • Silent about why, which is a fact about the game's data page and not about their orders.
  • Reuses the machinery that already puts a subject in a sentence — doubtSubject, which the "this region is not selling horses" hover already uses.
  • Two sentences to keep true instead of one, because GIVE … UNIT still needs the old one.
OPTION C — name the class and say why
SILVER cell This unit is giving away all its MAGIC items. The game's data page never says which items are MAGIC, so what leaves cannot be counted.
for GIVE 901 UNIT
This unit is giving away a whole class of goods, which cannot be counted.
  • Tells a player who wonders whether it is their mistake that it is not.
  • True and checkable — the page really never says.
  • Two sentences of hover on a cell that shows one character.
  • Explains an implementation limit to somebody who wants to write orders, and would need rewording if a future ruleset ever did print the flag.

The states this sentence has to survive

  • A class that is not one of the three — ALL WEAPONS, ALL FOOD. No doubt at all now; the cell shows a figure and this hover never appears. That is the change this bead is for.
  • GIVE 901 UNIT — hands over the whole unit, names no class, and keeps today's doubt. Shown above for B and C.
  • A class with an amount the rules do not define — GIVE 901 ALL WEAPONS EXCEPT 2. rules/give gives EXCEPT to the named-item forms only, so this stays unresolved and keeps the old sentence, whichever option wins.
  • No ruleset loaded — nothing resolves, every class doubts, and the old sentence is the only one that can be shown. Under B and C the class name is still available from the order itself, so naming it would still work; under A nothing changes.
  • Two doubts at once — a unit that both gives ALL MAGIC and taxes an unknown base shows one sentence, the first raised, exactly as today.
