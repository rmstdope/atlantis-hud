ah-don — Region name badges: one size for every province

Chosen: Option C — every name at a uniform 8 world units (letter-spacing 2.5, halo 2.2), scaling with the map, overflowing its province when wider than it, hidden at far zoom as today. Options A (the 4.62 floor) and B (6.5) were rejected as too small; the interview is recorded in bead ah-don’s design field.

Today each province name is fitted to its province: 11 world-units for a short name on a roomy province, shrinking as far as 4.62 (the floor) for a long name on a small one — so names range from small to large across the same map. Each variant below shows the same three provinces — INHEAD (large), CERAN (medium), MAPICLIR (a long name on a two-hex province) — at rest zoom and zoomed out one and a half steps. The border shown is the new B1 style from ah-f9c. The name still scales with the map as you zoom (it is fitted to ground it labels) and still hides at far zoom; what changes is that every province now uses the same size.

Current — fitted per province (for reference)

INHEAD renders at 11, CERAN at ~9, MAPICLIR at the 4.62 floor — the size variance the report is about.

Option A — everything at the current floor (4.62 world units)

Literally "the smallest size currently used". Uniform, and never overflows more than today's worst case — but small: at rest zoom it is ~4.6px on screen, comfortably readable only once you zoom in.

Option B — everything at a uniform 6.5 world units

One size, chosen for legibility at rest zoom rather than inherited from the old floor. A long name on a small province now overflows its outline a little (see MAPICLIR) — the price of any uniform size above the floor.

Option C — everything at a uniform 8 world units

Clearly readable at rest zoom; the overflow on small provinces grows accordingly.
