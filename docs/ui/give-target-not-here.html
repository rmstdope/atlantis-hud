A GIVE that goes nowhere — what the player sees (bead ah-djq)

The engine refuses a gift whose target it cannot find, and says so after the turn has run: GIVE: Nonexistant target (3247). — five times across two turns of the committed corpus. The goods stay put, the turn is spent, and the player finds out a week later. This bead warns before the file is sent.

Reading the five real cases changed what this bead should be. The bead says to warn when the id is “not visible in the report”. Only two of the five are that. The other three name a unit that is perfectly real and alive — standing in a different hex. The engine gives both the same message; the player needs different ones.

Decided, 2026-08-17, over two rounds. (1) The test is “is it in this hex”, and the line says which kind of mistake it is — Option C below. (2) The wording follows the teaching check, giving the four sentences in the section after it. (3) The toggle is Gifts to units that are not here, in the existing Orders group, on by default. Everything in the closing table is accepted as drawn.

The rules make the test a hex test, not an existence test — “Two units in different regions cannot normally interact” (neworigins-rules.html:830), and GIVE requires a target “which it is able to see” (:6236). And because the server runs GIVE in phase 4, before anything moves, the positions printed in this report are exactly the positions next turn's gift resolves against — so a report-based check is sound.

What counts as a target that is there Option C was chosen

OPTION A — rejected Anywhere in the report

Warn only when the id appears nowhere in the whole report. This is what the bead's own wording asks for.

12345

Catches 2 of the 5 real cases.

  • Cannot possibly be wrong: an id in no report is in no hex either.
  • Silent on three real, confirmed engine refusals — the commonest of the two kinds.

OPTION B — rejected In this hex, one message

Warn when the id is not among the units the report shows in the giver's own hex, whatever the rest of the report says.

Catches 5 of the 5.

OPTION C — chosen In this hex, and say which kind

Same coverage as B, but when the report does know the unit, the line says where it actually is. One toggle, one code, two sentences.
