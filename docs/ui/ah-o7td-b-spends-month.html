ah-o7td — Option B: everything that spends the month

The warning fires when a unit is given two things that occupy its month — the same set the application already uses to decide whether a unit is idle and whether it can be offered as somebody’s spare teacher (spends_the_month, which drives the Units that do nothing warning you already have).

That set is the rules’ six — TEACH, STUDY, PRODUCE, BUILD, ENTERTAIN, WORK — and also MOVE, ADVANCE, SAIL, TAX, PILLAGE, IDLE and ANNIHILATE. CAST is excluded, as the rules require.

Option B — wide: whatever the app already counts as spending a month

unit 5187 STUDY Combat PRODUCE wood a second order for the month: line 2 already gives this unit STUDY, and only one of the two will run

Woodsmen (5187) — 12 men, forest (18,4).

Fires the common one — move, then work

unit 5187 MOVE N NE STUDY Combat a second order for the month: line 2 already gives this unit MOVE, and only one of the two will run

⚠ This is the case Option A stays silent on. A unit that walks two hexes has spent its month walking; the STUDY underneath it is a wasted turn the player does not find out about until the report comes back.

Fires sail, then produce

unit 5187 SAIL N NW PRODUCE fish a second order for the month: line 2 already gives this unit SAIL, and only one of the two will run

Fires tax, then work

unit 5187 TAX WORK a second order for the month: line 2 already gives this unit TAX, and only one of the two will run

Whether this one is right is the part of Option B least settled by the rules text. TAX is processed in its own phase, above the month-long block — but the application already treats a taxing unit as having spent its month, and a unit told to tax and work is a unit whose player expected both.

Fires three of them, marked twice

unit 5187 MOVE N BUILD Tower a second order for the month: line 2 already gives this unit MOVE, and only one of the two will run ENTERTAIN a second order for the month: line 2 already gives this unit MOVE, and only one of the two will run

The first one is left alone — it is the one that will run. Each later one gets its own marker, the way form-alias-reused already marks every repeat and names the first.

Silent GIVE, BUY, GUARD beside one month-long order

✓ No warning, on every option. None of these spends the month.

What B buys: it catches the mistake players actually make, and it uses one definition of “spends the month” across the whole application — the same one that decides whether a unit is idle. What B costs: the rules do not print MOVE, TAX or PILLAGE under “Month long orders”, so those three cases rest on the app’s judgement rather than a sentence you can point at. If any of them is legal in your game, the warning is noise on every such unit.
