Changing a game’s ruleset mid-game

Chosen: the ruleset is changed in Settings → This game; a change that leaves names undefined is warned about in a dialog naming the affected turns; a change with nothing missing happens at once; map sizes are kept. Example: a game on New Origins with 5 turns loaded.

1. As Settings → This game opens

The list shows the current ruleset; Change ruleset is dimmed until another is chosen. The old line “The ruleset is chosen when this game is created.” is gone.
