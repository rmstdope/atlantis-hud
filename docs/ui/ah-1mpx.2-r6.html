ah-1mpx.2 — round 6: how a unit gets in, and what the dock remembers

Two things the earlier rounds assumed. The first is a surprise from the code: round 3 settled the gesture as right-click → Add to army, but this application has no context menu anywhere. The only right-click in the whole app recentres the map. So the gesture is not a line of wiring — it is the first menu of its kind, and this bead would be the one to build it.

That matters beyond the work, because a right-click is a mouse. The units table is fully keyboard-navigable today — arrows move the selection, Enter opens the unit — and a mouse-only route into an Army would be the first thing in the dock a keyboard cannot reach.

T1 — the way in, in this bead

Dragging arrives in ah-1mpx.4. Until then this is the only way a unit joins an Army, so whatever is chosen here has to carry the whole feature on its own for a release.

T2 — what the dock is showing when you come back

The workspace store persists panel heights, column widths and column order, but deliberately not the selection — the selected hex and unit are forgotten on reload. The source is a new kind of state and has to choose a side.

Option A — the source is forgotten, like the selection recommended
reopen the application → This hex
load next month's report → stays where it is
open a different game → This hex
click a hex while on an Army → stays on the Army, This hex lights in brass
  • Matches the selection exactly — the app already forgets which hex and which unit you were on, so forgetting which list is the same promise.
  • You always reopen to the same known place, and a rail entry is one click away.
  • If you spend a month working inside one Army, you re-pick it every time you open the app.
Option B — the source is remembered per game
reopen the application → Northern Host, as you left it
load next month's report → stays where it is
open a different game → This hex (its Armies are not this game's)
the remembered Army was deleted → This hex
  • Working through one force over several sittings costs nothing to resume.
  • You reopen the application to a list that is not about the hex on the map, and the map and the dock disagree from the first frame — before you did anything to cause it.
  • A remembered id that no longer exists is a new case to get right, in a store that today persists only numbers and flags.
