Trident order suggestions in the existing editor

A player chooses the ruleset while creating a game. That choice remains fixed, and the editor and command palette quietly follow it. In a New Age: Trident game, the four Trident order names appear with the existing command suggestions; New Origins-only names do not.

CREATE, EXPLORE and QUEST are offered in the same two existing places. Typing narrows a suggestion list; no matching name leaves it closed; Enter or Tab inserts the selected command. The palette remains one scrollable list, where these names join the existing rows marked “order”. No new shortcut, dialog, focus movement, or separate command-help surface is added.

The selected ruleset

New Age: Trident
The ruleset is chosen when this game is created.

The game settings show the chosen ruleset as a read-only value. A player creates another game to use a different ruleset; an existing game never changes its command language, so there is no transition between one world's suggestions and another's.

States that stay within the existing surfaces

Too few or no matches

CAPITAL appears after “CAP”. An unknown word shows no suggestion; the editor’s existing problem marker remains the feedback.

Too many matches

The command palette remains its existing scrollable list. New order names do not create a section or a second help page.

Narrow window

The existing editor and palette widths continue to govern wrapping and scrolling. No ruleset label adds a second line to either compact surface.
