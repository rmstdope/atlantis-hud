Export with errors — the agreed confirmation

The player is warned how many errors there are and asked to confirm. They are never stopped from exporting.

The agreed dialog chosen

Pressing Export orders or Export orders with descriptions while the orders have one or more errors closes the Export menu and opens this, over a darkened workspace. Focus starts on Cancel. With no errors nothing appears and the file is saved straight away, as today; warnings alone never bring it up.

What closes it

  • Export anyway — closes the dialog and saves the orders exactly as they are (the save dialog on the desktop, a download in the browser).
  • Cancel, Escape, Enter (focus starts on Cancel), or a press on the darkened area — closes it, nothing is saved, focus returns to the Export button.
  • Show errors — closes it, nothing is saved, and jumps to the first error in the orders, as the ‹ › problem buttons and F8 do (see ah-koleq-show-errors.html). Only when no error sits on an order line does it open the Problems tab under the "to check" chip instead.
  • Exporting while the checker is still checking the latest typing waits for that check, then warns or saves.
  • Asked every time; there is no "don't ask again".
