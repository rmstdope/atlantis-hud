ah-coij — the sign-in goes away; the password is asked for each time

There is no signed-in state on a New Age world any more, on Arcanum or on Trident. Nothing is held between actions: each of Fetch and Send logs in with the faction number and password typed into its own dialog, does the one thing it was asked to do, and forgets the token. A reload, a game switch and a ruleset change all become uneventful, because there was never anything to lose.

The header chip that read Sign in to Arcanum, and the faction-name chip with its popover behind it, are replaced by one button that always says Fetch and always does the same thing.

Fetch and Send in the web version — when New Age won't answer

In a browser, Fetch and Send for a New Age game work exactly as they do in the desktop app: the same button, the same dialogs, the same sign-in each time, the same messages. The one new case is a page served from a web address the New Age server does not accept. Today that is every address except atlantis-hud.kurelid.se — anyone hosting the web version themselves.

The catch: a browser cannot tell the server is down apart from the server won't talk to this web address. Both look like a connection that failed. So this is really about how Could not reach atlantis-newage.com. should read on the web. It only ever appears at the sign-in step — once sign-in works, the address has been accepted — so it's two sentences: one in Fetch, one in Send.

Chosen: A — one sentence on every web address. B and C are kept below as what was considered and rejected. The desktop app's wording is unchanged.

A — one sentence everywhere on the web

Every web address gets the same, longer sentence, naming both possible causes. Nothing needs to know which addresses the server accepts. Cost: a player on atlantis-hud.kurelid.se whose server is simply down is told about a web-address problem they don't have.
