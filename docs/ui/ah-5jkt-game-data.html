Reading the game data — the reference dialog and the way in

The application scrapes the game server's rules and data pages into ruleset.json, but nothing shows it to you. This adds a way to look a thing up.

The constraint worth knowing before you judge the layouts: the scraped data has no prose at all. There are no descriptions, no flavour text, no rules explanations — only numbers and cross-references. Everything below is drawn from the real shipped file: 96 skills, 171 items, 10 buildings. A "game data" dialog is therefore a stat block, and the honest question is how to make a stat block worth opening.

Note the coverage gap, which is real and cannot be fixed here: buildings holds only the ten fortifications — TOWER FORT CASTLE CITADEL, their four magical twins, HERMITS HUT and STOCKADE. A Mine, a Shaft, a road or a Longship is not in there (ships are items).

Both drawn with the real values for MINI (mining), LONG (Longship) and BALR (balrog). Cross-references — what a skill produces, what it requires — are shown as links that open that entry.

3 · Getting there from the palette

The palette holds units, regions, actions and order help. Adding 277 things of a new kind changes what it feels like — with an empty query it lists whatever comes first, twelve at a time.

AMixed in with everything else

Game data entries join the same flat list, marked with their own kind label. Typing mining finds the skill alongside anything else called that.
mining MINIskill
Miners (7227)unit
MinersA (5104)unit
mithril MITHitem
MinersM (3826)unit
  • One box, one habit — nothing new to learn or remember
  • Finds a thing whether it is your unit or a rule about mining
  • 277 entries dilute the list; your own units get pushed down by data you did not want
  • With an empty query the palette becomes a wall of game data

BBehind a prefix

Typing ? first switches the palette to game data only, the way many editors scope a search. Without the prefix the palette is exactly as it is today.
mining MINIskill
mithril MITHitem
mithril armor MARMitem
mithril sword MSWOitem
  • Today's palette is untouched — no dilution, no wall of data
  • Scopes the search, so results are all of one sort and easy to scan
  • A prefix is a thing to know; nothing on screen teaches it
  • Two habits instead of one, for a feature you may use rarely
