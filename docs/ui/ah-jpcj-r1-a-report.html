Importing a map export — Option B: it is a report, and you are asked

The rule. A map export stays an ordinary report file. The routing the app already has does the work: an ally’s raises the existing Report from another faction prompt, and yours would load — except that loading a map export over your own turn destroys it, so the one thing added is a prompt for your own export. Nothing is ever done silently: every map export asks first.

State 1 An ally’s map export, same turn as yours

Exactly the prompt the app shows today for any allied report — no new component, no new words.

Borg TNG (95) turn 71
11 regions · 34 units

map-turn-71-level-1.txt is Mantzikert (39)’s report for turn 71 — the same turn as your own report for Borg TNG (95).

Merge adds everywhere Mantzikert (39) went to your map and leaves you playing Borg TNG (95).

Switch faction opens the report itself: the map, the units and the orders all become Mantzikert (39)’s.

your map — 11 hexes
  • Zero new UI. This is the component and the wording that already ship.
  • “Switch faction” on a map export makes you a faction with no units and no orders — the prompt offers it anyway.
  • On Merge, status: merged 19 regions from Mantzikert (39), turn 71 — 8 new to your map

State 2 An ally’s map export from a different turn

Their turn 70 export while you hold turn 71. The Merge button is removed, not disabled — the app’s existing rule.

Borg TNG (95) turn 71

map-turn-70-level-1.txt is Mantzikert (39)’s report for turn 70, and you have Borg TNG (95)’s turn 71 open. Merging needs a report from turn 71, so only switching is on offer.

Turn 70 is older than the turn you have loaded, so it may not be the latest report there is.

Switch faction opens the report itself: the map, the units and the orders all become Mantzikert (39)’s.

your map — 11 hexes
  • The map in that file cannot be taken at all. The only offer is to become a faction with no units.
  • An ally who exported on a different turn from yours has sent you a file you can do nothing with.

State 3 Your own map export, back into the same game   this is what you did

This is the state that needs something new. Without a prompt, the file replaces your turn.

The new prompt Option B has to add
Borg TNG (95) turn 71

map-turn-71-level-1.txt is a map export from your own faction, Borg TNG (95), turn 71. It holds hexes only — no units, no orders and no events.

Add to map keeps the turn you have open and takes any hex the file knows and your map does not.

Open it instead replaces the turn on screen with the file, and your units, orders and events for turn 71 go with it.

your map — 11 hexes
  • Nothing is destroyed without being warned about first.
  • A third prompt to design, word and test — and a destructive option kept on offer.
  • The question is put every time, including the common case where the answer adds nothing.

State 4 A map export with no game open

no report loaded
11 regions · 0 units
map from the file — 11 hexes
  • It just opens, like any first report — a map export can start a game under Option B.
  • The game it starts has a faction with no units and no orders template, which will confuse the next thing you do.

State 5 A map export among twenty files (the batch importer)

Borg TNG (95) turn 71

Imported 4 turns for Borg TNG (95). Turn 71 is on screen.

t69.rep — imported as turn 69
t70.rep — imported as turn 70
t71.rep — imported as turn 71
map-turn-71-level-1.txt — imported as turn 71
  • The batch importer never asks. A map export in a batch overwrites the real turn 71 silently — the prompt in State 3 does not exist on this path.
What Option B costs. It keeps a destructive option on offer and puts a question in front of the player every time. And the batch importer, which asks nothing by design, cannot be protected the same way — so State 5 stays wrong unless the file is recognised as a map export there too, which is most of Option A’s work anyway.
Compare with Option A — a map export is map knowledge and nothing else, so it can never destroy anything and is never asked about. Open both before choosing; the difference is in what happens in States 3 and 5, and it does not survive being described.
