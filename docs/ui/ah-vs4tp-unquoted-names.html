Warning on a name or description that loses words — chosen design (ah-vs4tp)

Without double quotes the game keeps only the first word of every NAME and DESCRIBE (rules/orders; rules/name; rules/describe). A quote that is opened but never closed makes it read nothing at all. Chosen: F1 Add quotes button, U1 dropped words underlined, S1 every form, Q1 unclosed quote warned too, W1 wording, T1 one switch.
