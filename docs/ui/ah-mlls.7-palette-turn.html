Import, Fetch and Send from the command palette

Import, Fetch and Send are the buttons you press most often in a turn, and today they are only in the top bar. Here they are also in the command palette (Ctrl/⌘ K). They appear only where the top bar has them: no Fetch or Send for a game the app cannot reach, and on a New Origins game Fetch has only one choice (its window has no "Latest / All" question). Four questions, each with drawn variants.

1 · Fetch's two choices

On a New Age game, the Fetch window asks for faction and password and then whether to fetch the latest report or every report not yet fetched.

ATwo rows, each one choice already tickedrecommended

Each row opens the same Fetch window with that choice already selected. You still give the password and press Fetch.

2 · When Send or Import can't be used right now

The top bar greys Send out when the orders have no #atlantis line, and greys Import out while an import is running. What does the palette do then?

AShown greyed, with the reasonrecommended

The row is still found, drawn dim, with the top bar's own reason beside it. Enter does nothing; the highlight skips it.

sen|
Send ordersThese orders have no #atlantis line, so the server cannot tell which faction they belong to.action
Sentinel Watch (204)unit
  • Matches the greyed button, and says why — you are not left wondering where Send went.
  • A row you can see but not choose.

BLeft out

The row is simply not in the list until it can be used.

sen|
Sentinel Watch (204)unit
  • Every row in the list works.
  • Send vanishes without a word; you have to look at the top bar to find out why.

The top bar greys Import in two cases: an import is already running, or this game's saved data is held open in another Atlantis HUD tab.
