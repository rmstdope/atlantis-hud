Sharing mages with an ally — A: the file road we already have

The map export already does exactly this shape of thing: it writes a text file with a marker comment on its first line, and the ordinary Open / drag-and-drop path recognises the marker and routes it somewhere other than “load this as my turn report”. A mage sheet would be a second passenger on that same road — ExportMenu gains one entry, and the import prompt gains one more shape.

Nothing new is opened, nothing new is navigated to. You mail the file to your ally; they open it the same way they open anything else.
