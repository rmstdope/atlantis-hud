ah-1wcw.2 — selling, gifts, entertaining and magic

ah-1wcw.1 built the Silver column and priced TAX, WORK and STUDY. This bead adds the income it left. It changes nothing about the column, the cell, the colours, the sorting or the shape of the hover — the panel keeps its four generic rows, so a new income source simply makes In bigger. The only new interface is two dim note lines, and the cases where one appears.

This design was settled twice. Two planners interviewed the navigator about this bead without knowing the other had, and the navigator gave opposite answers to three questions. The navigator was shown the conflict and chose; the overturned answers are recorded at the foot of this page so nobody revives them. ah-ywj7 is the bead about the collision.

The reasoning in each case: 0 is not a guess where the order genuinely earns nothing, and a doubt reserved for what is truly unknowable stays worth reading.
