What this costs

sortUnitsForDisplay, which picks the hex's default selected unit, orders own-first then by name, and today that is exactly what the table opens in. Changing only the table would leave the selected unit somewhere other than the top row, so variant A moves both: the unit the app picks for you when you click a hex is the own unit with the lowest Id, and it is still the top row of the table.
