A BUILD that builds nothing — wording proposals (bead ah-vkut)

A unit with the Building skill can write BUILD or BUILD COMPLETE while it is standing in no structure at all. Neither form names what to work on, so from outside the order does nothing and the unit's whole month is spent for nothing. The other forms — BUILD Tower, BUILD Tower COMPLETE, BUILD HELP 4021 — each say what to work on, and are fine from outside.

This is the sibling of ah-90w (“Building what is built”), which landed the Intent::Build shape and the Building group in the Warnings tab. That check deliberately went silent on a unit in no structure, calling it “a different mistake and not this bead's”. This is that different mistake.

Three things to decide. The wording (§1), the Warnings-tab entry (§2), and whether you accept the LEAVE consequence in §3.

The same message covers both forms. BUILD and BUILD COMPLETE are the same mistake and parse to the same intent (founding: None, helping: None), so neither wording distinguishes them. Say so if you would rather BUILD COMPLETE read differently.

§3  When it is silent — and the one case worth your eye

The check reads where the unit stands after its own orders have run, through the existing structure_after_orders helper — the same rule every other check in this file uses, and the one ah-mjy was filed to enforce. That settles ENTER for free, and produces one consequence you should look at.

The unit's ordersVerdictWhy
BUILD ⚠ warnsIn no structure per the report, and the orders do not move it into one.
BUILD COMPLETE ⚠ warnsSame intent; COMPLETE says when to stop, not what to work on.
ENTER 4 BUILD silentThe ENTER runs first, so the unit is inside structure 4 when BUILD runs. The normal, correct way to write this.
LEAVE BUILD ⚠ warnsThe case to look at. The unit steps out, then builds nothing. Correct by the same rule that makes ENTER silent — but it is the one line here that warns about a unit the report shows safely inside a structure.
BUILD Tower silentNames what to found; perfectly good from outside.
BUILD HELP 4021 silentNames whose structure to work on. Silent whether or not either unit is inside one.
BUILD  (unit inside structure 4) silentCarrying on with the structure it is in — and if that structure is finished, ah-90w's check has it.
BUILD  (another faction's unit) silentOnly our own units are checked, as everywhere else.
Decided: the LEAVE row warns. Consistent with every other check in the file, and the unit genuinely does waste its month.

§4  Helping a unit that is not building your addition — round two

You asked for BUILD HELP 4021 to warn when 4021 is one of our own units that is not building at all — there is nothing to help with, so the helper's month is spent for nothing. That is a cleaner rule than the one I proposed, and it uses only intents we already parse. Here is every case it has to answer.

The helper writes …VerdictWhy
BUILD HELP 4021 (4021 ours, has no BUILD) ⚠ warnsThe case you asked for. 4021 is doing something else this month; nothing to help with.
BUILD HELP 4021 (4021 ours, orders BUILD) silentThere is work to help with. Whether 4021's own BUILD is any good is judged on 4021's own line.
BUILD HELP 4021 (4021 ours, orders BUILD, in no structure) silent
(4021 warns on its own line)		One mistake, marked once, where it was made. Or should the helper be told too? — that is question 1 below.
BUILD HELP 9999 (not in this hex) silentCannot be judged — may be a unit forming this month with no number yet. Same rule ah-90w uses.
BUILD HELP faction 3 / NEW 1 / 0 silentAnother faction's unit, one formed this month, or a discard. Not ours to read orders for.
BUILD HELP 4021 (4021 ours, orders BUILD Tower) silentFounding counts as building; there is work to help with.
