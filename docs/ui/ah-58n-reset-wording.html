Says the outcome rather than the casualties, which is how this application usually words a consequence. But it never names the notes or the map, so a player with fifty hex notes is not told they go.

W3 — short, and unmistakably destructive

● Binding of the North↺✕

Reset “Binding of the North”? Everything in it is erased; only the name and ruleset are kept.

ResetCancel

One sentence, and “everything” is a promise that stays true when the next thing is added to a game. Danger-red border and button like delete, because it is nearly as final. Names nothing specific, so it relies on the player knowing what is in there.

The backup question, drawn

Reset is unrecoverable and Export already exists. Three ways the confirmation could acknowledge that.

B1 — say nothing

Reset “Binding of the North”? Its turns, orders, remembered map and notes are erased. The game keeps its name and ruleset.

ResetCancel

The delete confirmation says nothing either, and delete is worse. Consistent, and the shortest path for a player resetting a scratch game for the fifth time.

B2 — mention it

Reset “Binding of the North”? Its turns, orders, remembered map and notes are erased. The game keeps its name and ruleset.

Export it first if you might want it back.

ResetCancel

One dim line, no new machinery, and the player is told the door exists. Adds a line to a panel that appears on every reset for ever.

B3 — offer it

Reset “Binding of the North”? Its turns, orders, remembered map and notes are erased. The game keeps its name and ruleset.

Export firstResetCancel

Three buttons in a panel that had two, and “Export first” has to save a file and then come back to a panel that is still open — a second flow to design, and a second thing that can fail mid-reset.
