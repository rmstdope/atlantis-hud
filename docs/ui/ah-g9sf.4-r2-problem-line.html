A Farm of wood, a Farm of stone — round 2: the problem line

Settled in round 1. Q1 — a build the game will refuse is reported where every other trouble with an order line is reported, not in the unit table's hover. Q2 A — when a unit holds both and the rule picks stone, nothing new is said: the stone drops in the cell and the existing “Spends 10 STON on a new Farm this month.” is the whole story. Q3 B — a month that spends stone then wood says it in one sentence: “Spends 4 STON and 6 WOOD on a new Farm this month — all the stone it has, then wood for the rest.” Q4 A — the editor offers COMPLETE, STONE and WOOD as bare words, with nothing appended.

Round 1's answer settles where. Four things it does not settle: how loudly, in what words, whether the region's own problem list carries it too, and what happens to a unit that has neither material.

The shape a problem already has. It appears in three places at once, from one source: a coloured dot in the editor's left margin with a wavy line under the offending words; a count in the strip beneath (0 errors · 2 warnings), walkable with F8; and a line in the region's Problems pane. The message is written as a phrase completing the unit's name — “Miners (7227) cannot build a Mine: needs mining 3, has mining 1”, “is in no structure to build in”. Every option below keeps that shape.
Chosen, and this is the record. Q5 A — a warning: amber dot, amber wavy line, counted in the strip, walkable with F8, and 0 errors keeps meaning “well formed”. Q6 B — “cannot build a Farm from wood: has no wood, but 20 stone”, falling back to “… has no wood” when the unit holds neither. Q7 A — a unit carrying neither material is caught too, in the same colour and the same places: “cannot build a Farm: has neither wood nor stone”.

Q5 How loudly — a warning, or an error?

The distinction the application draws today: errors are lines the game will not accept at all, warnings are lines it accepts and which then achieve nothing. This case is arguably both — the rules say the order “will fail with an error”, and the month is wasted as a result. Only the colour, the count it joins and the green 0 errors differ.

Q6 The exact words

This is the string that ships, read after the unit's name in the region's problem list and after a BUILD chip in the editor's own list. Shown in both places for the fit. The same sentence must work for STONE with no stone.

Q7 A unit carrying neither wood nor stone

Not a new case — it exists in the older game world too — but the application is silent about it today, and everything needed to catch it arrives with this change. Plain BUILD Farm, nothing in the packs.
