Trident construction — when a new building cannot start here

When Trident certainly refuses a new building at this site, the player is told in the two places this application already reports order trouble: the problem list beneath the orders editor, and the hex's own Problems section. It is an ordinary problem in every sense — counted among the turn's warnings, marked in the editor's margin beside the BUILD line, and a stop on the F8 walk. The forecast keeps the material back whether or not the explanation is shown.

Every refused unit gets its own line with the whole sentence, however many share the region's one reason. The sentence is word for word the same as the editor's.

The four sentences

No settlement
Cannot start a Caravanserai here: this region has no settlement. No wood will be used.
One already exists
Cannot start a Palace here: this region already has a Palace. No stone will be used.
Town Hall
Cannot start a Town Hall here: this region already has a Town Hall. No stone will be used.
Canal
Cannot start a Mystic Canal here: this region already has a Mystic Canal. No stone will be used.
Variable materials. “wood” and “stone” above stand for the material that this particular forecast would otherwise spend. If either material could be used and the forecast cannot tell which one, the sentence stops after the reason and does not claim that either will be used. On a narrow window the entry wraps within its list; the position chip beside ‹ › drops out, as it does for every problem.

Settings › Building

Construction sites the game will refuse
A BUILD order that cannot start a new building in this region.

On by default, remembered across reloads and report changes. Turned off, the check is simply not made: no entry in either list, nothing added to the counts, no bar in the margin, no stop on the walk, and nothing anywhere saying something was hidden — the same way every other warning setting here behaves. The forecast still keeps the material back.
