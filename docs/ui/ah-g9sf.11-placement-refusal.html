Trident construction — when a new building cannot start here

An amber explanation appears directly beneath a BUILD order only when Trident certainly refuses a new building at that site. It names the building, the precise reason, and the material the forecast retains. The warning is not a control: focus stays in the orders editor, no shortcut is added, and all existing keys keep their meanings.

Variable materials. “wood” and “stone” above stand for the material that this particular forecast would otherwise spend. If either material could be used and the forecast cannot tell which one, it does not claim that either will be used. On a narrow window, the warning wraps beneath its own order as one block; it never widens the editor or hides the order.
