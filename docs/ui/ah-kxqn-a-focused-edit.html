Map sizes · focused editing

Compact rows set the map sizes while creating a world. Once created, a short summary in World settings opens the same focused window to change them.

“Edit map sizes” opens with focus on Surface width. Cancel, Escape or × leave every setting unchanged and return focus to Edit map sizes. Save returns to World settings with its summary updated. The draft survives an invalid entry until it is corrected, but not closing without saving.

Saving a smaller level or removing one

Save map sizes?

Making Underworld smaller may remove parts of this level that are outside its new size.

Keep editingSave map sizes

This confirmation appears only when a saved change makes a configured level smaller or clears both its fields. “Keep editing” returns focus to the changed field and leaves the draft intact. “Save map sizes” applies the change. Adding a level, making a level larger, or changing either wrapping choice saves without this extra window.

The rows become small blocks at a narrow width. Focus moves through every width and height, wrapping, Cancel and Save map sizes. While a game choice is loading, the creation window says “Loading map levels…” and fields are unavailable. If levels cannot be loaded, it says “Map levels could not be loaded. Try again.”
