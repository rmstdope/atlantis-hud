Units in hex — the Structure column

Today the column reads [12]. The region pane, two panes away, writes the same structure as Odds and Ends [12] · Fort. This page is about closing that gap without wrecking a table that is already dense.

The constraint that shapes every option: every row is pinned to one fixed height so the pane can window three hundred units, and the table is table-fixed. So the text cannot wrap onto a second line — whatever does not fit is cut off. The only real choices are how much width the column takes from its neighbours, and what gets dropped when it still does not fit.

Data below is Inholm (1:7,53), the hex the smoke suite uses: a city with 24 structures and 92 units. The Structure column is outlined in brass in each table.

The three options

Each shows the same four rows. Watch what the Skills and Items columns lose.

AGive the column the room — 13rem, truncate what still overflows

The column matches the region pane exactly: Odds and Ends [12] · Fort. It takes 8rem from the two unsized columns, Skills and Items, which already truncate today. Anything still too long is cut with an ellipsis and the full text is in the hover tooltip.

  • Reads exactly like the region pane — the same structure, said the same way, in both places
  • Type is visible at a glance: you can see who is in a ship and who is in a fort
  • Skills and Items lose about 8rem between them, and they already truncate
  • A long structure name still gets cut, so the tooltip is doing real work

BKeep it narrow — name only, everything else in the tooltip

The column widens only to 8rem and shows the structure's name. The number and the type live in the hover tooltip, along with the full name. Costs the neighbours almost nothing.

  • Arguably does not meet the bead's own acceptance, which asks for all three on screen

CFull form, but drop the type when it merely repeats the name

Same as A, except · Fort is omitted when the type adds nothing the name has not already said. Many structures are named after what they are, so in practice this buys back most of the width A spends — the column can then sit at 11rem.

  • Full information wherever it adds anything, and never says the same word twice
  • 2rem cheaper than A in the common case
  • The column is no longer a fixed shape — two rows can be formatted differently
  • A rule with a comparison in it is a rule to get wrong; needs its own test
