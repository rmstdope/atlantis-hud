ah-g6gn.2 — the map routes a flying fleet over land

data/BALL, verbatim: “Balloon [BALL]. This is a flying ‘ship’ with a capacity of 100 and a speed of 4 hexes per month.” rules/movement_sailing never mentions flying ships at all, which is why the evidence is the catalogue’s own prose.

Today the map is blind to it. movement::plan::blocks is handed a movement mode and never a fleet, so a balloon is refused every inland hex, in the route planner and in the order tracer alike — while ah-sefq’s Problems warning already goes quiet about the very same order. This bead closes that: the fleet’s flying-ness reaches the terrain test, and afterwards the two surfaces agree about a balloon everywhere.

The case a balloon docked in a coastal forest, asked for a mountain three hexes inland

The question — how sure must the application be before it flies a fleet over a mountain?

“Does this fleet fly?” has three answers, not two. fleet_flies — ah-sefq’s, and the one reading of the question — answers yes when a hull in the fleet is one the catalogue calls flying, no when every hull was found and none of them flies, and cannot say when there is a hull the catalogue does not carry. A report can still price such a fleet from its own words (Sailors: 4/4, MaxSpeed: 4), so “cannot say” is reachable and has to be answered for.

ah-sefq settled it for the warning: it stays quiet unless the answer is a definite no. The two options below are whether the map reads it the same way.

OPTION A the map reads it exactly as Problems does

Anything but a definite no frees the fleet from land. One reading of “does this fleet fly”, used identically by both surfaces, so they can never disagree about any fleet at all.

The same, in the order tracer a written SAIL over land

The tracer draws intent rather than legality, so it never refuses — it dots the line from the first step the game would refuse. Under either option a balloon’s SAIL SE SE over land is left undotted; the options differ only for the unrecognised hull, which stays dotted under B and goes solid under A.

Not in this bead

  • Whether a flying fleet may end its month over ocean. It is a ship; the rules give ships no drowning rule, and the planner’s drowning guard has only ever applied to a flying unit. Unchanged.
  • Speed and cost. A flying fleet sails at its own MaxSpeed and pays one movement point a hex, as every fleet does — “For a fleet to enter any region only costs one movement point”.
  • The two other sentences of the sailing paragraph: single hex land masses, and leaving by the same side or one adjacent. Neither is modelled anywhere today.
  • Anything new on screen. No new label, no new refusal, no new warning — only which steps are refused changes.
