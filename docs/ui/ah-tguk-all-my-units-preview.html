States that do not change

  • No orders written. No preview, so the list is byte-identical to today’s.
  • No report loaded. “No report loaded.” — unchanged.
  • A report with no own units. “No units of your own in this turn’s report.” — unchanged.
  • No hex selected. All my units still previews: it never needed a hex, and now it does not need one to show the month either.
  • The filter box. Unchanged, and it now narrows previewed rows too — typing new finds the FORMed unit.
  • Keyboard, focus, Escape, the row cursor. Untouched; a previewed row is an ordinary row.
  • A narrow pane. The Name cell truncates as it always has, marker included.
