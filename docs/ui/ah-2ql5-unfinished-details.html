Decided — no question needed

  • A structure the report never described (shown as a bare [11]) gets no mark: nothing is known about it.
  • A remembered hex from an older report marks what that report said.
  • Sorting and filtering are unchanged; the mark is not a separate column.
  • The mark is decoration on the existing cell: nothing new to tab to, no shortcut.
