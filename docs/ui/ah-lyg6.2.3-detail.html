ah-lyg6.2.3 — the level, what may be chosen, and when it is written

Three more questions about the same pane. The blocks below are drawn in variant B's shape for clarity, but every one of them applies whichever of A, B or C you pick in the first file (ah-lyg6.2.3-choose.html).

The rule this rests on — rules/study, quoted: "STUDY [skill] … STUDY [skill] [level] … Spend the month studying the specified skill. A level may be specified which means that study will be continued from turn to turn until the unit reaches that skill level." So a level is optional in the game itself, and it means keep going until you get there — not this month only.

Two facts about the application as it stands, because they bear on questions 2 and 4. There is no numeric input anywhere in Atlantis HUD, so the level is drawn here as a small menu rather than a spinner. And every free-text field that is stored today commits explicitly — a hex note has a Save button, ⌘↵ and Esc, and no field in the application saves itself while you type.

Every plan names a skill. Does it also have to name a level?

The same menu as E3, but the greyed rows cannot be chosen at all — they are shown so you know they exist and why they are out of reach. No warning line is ever needed, because no impossible plan can be saved.
