ah-h8z — Resizable left and right map panes

The two rails float over the map with live map between them, so the resize handle hangs on each rail's inner edge (the side facing the map). Each rail resizes independently, with the same gestures as the unit/orders splitter you chose in ah-13o: drag; arrow keys when the handle has keyboard focus; double-click or Enter to reset to the default width; Escape cancels a drag. Hover the handles below — they are live.

Decisions (recorded from the planning discussion): variant B; the rails resize independently; the map view is left alone on release (no re-fit); widths persist with the workspace layout and reset by double-click or Enter; limits 12–45rem and never more than half the window; arrow keys move the edge in screen direction (ArrowRight grows the left rail, shrinks the right); handle labels "Resize region panel" and "Resize unit and orders panels"; help-overlay entry under Panels and windows — description "Resize a side pane", mouse "Drag the pill on its inner edge", keys "Tab to the pill, then ←/→".
