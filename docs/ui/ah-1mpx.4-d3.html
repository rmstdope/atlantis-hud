ah-1mpx.4 — round 3: every new string, as it will ship

Settled: drag onto an Army or onto + New Army; a bulk line above the table at two or more picked, carrying every bulk action, with the header's Add to army ▾ standing down while it is up; the filter narrows the pick; a press outside the pick collapses it; an Army holding some of the pick is offered with a note.

What is left is the wording. Nothing below is a paraphrase — whatever is chosen is what gets typed into the code, so read them as lines rather than as descriptions.

W1 — the bulk line, in both its shapes

Outside an Army it can only add. Inside one it can also remove. Same line, same place, one button more.

Set A — plain, and the Army named recommended
on All my units
3 units picked. Add to army…Clear
inside Northern Host
3 units picked. Add to army… Remove from Northern Host Clear
  • The removal names what it removes from, so there is no way to read it as “delete these units”.
  • Matches the delete confirmation already shipped, which also names the Army: Delete Northern Host? The 12 units in it are not affected.
  • Three buttons, and a long Army name pushes Clear towards the edge on a narrow window.
Set B — short, and the Army implied
on All my units
3 selected Add to army…Clear
inside Northern Host
3 selected Add to army… Remove Clear
  • Shortest, and never reflows however long the Army name is.
  • “selected” is the word this application uses for the cursor row that drives the Unit panel and the map. Round 3 chose picked for exactly this reason.
  • A bare Remove sitting beside a bare Clear gives no clue which of the two touches storage.
Set C — the count on the buttons
on All my units
Shieldwall, Outriders, Bowmen Add 3 to army…Clear
inside Northern Host
Shieldwall, Outriders, Bowmen Add 3 to army… Remove 3 Clear
  • Names the units rather than counting them, which is the one thing the wash cannot do for rows scrolled out of view.
  • Twelve picked units is a line of names that truncates to nothing useful, and it has to decide where to cut.
  • Puts the count on two buttons instead of once in the sentence, so it is stated twice and can disagree with itself.

W4 — the empty-Army line, now that dragging exists

ah-1mpx.2 shipped this wording deliberately, so it would still be true once this bead landed:

Option A — leave it exactly as it is recommended
Northern Host has no units yet. Add units to it with Add to army, on any unit in any list.
  • Still true: Add to army is on the pane header, in the bulk line and in the right-click menu, and it is the one route a keyboard can take.
  • No churn on a string that shipped one bead ago and was written for this moment.
  • Says nothing about the gesture most people will actually reach for.
Option B — name the drag as well
Northern Host has no units yet. Drag units onto it, or use Add to army on any unit in any list.
  • Names the cheap gesture first, which is what the epic asked for: adding units must not be tedious.
  • The empty Army is the one moment the application has your attention about how to fill it.
  • “Drag units onto it” is read while looking at the Army's own empty table — “it” is the rail entry to the left, not the space the sentence is written in.

Everything not asked on this page is either settled in rounds 1 and 2, carried in from the epic's round 3, or mine: a bulk add is one write and one rollback (like removeUnits), a failed one reports could not save <the Army's name> exactly as ah-1mpx.2 S4 decided, Escape cancels a drag in flight before it does anything else, and Ctrl/Cmd+A inside the filter box still selects the text in the filter box.
