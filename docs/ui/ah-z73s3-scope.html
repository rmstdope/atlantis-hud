ah-z73s.3 — which arrivals the crew check follows

Today the undercrewed check goes completely silent for a fleet the moment men of any race arrive at any unit aboard it. ah-z73s.2 shipped the machinery to compute the merged skill, so the silence can go — but only for arrivals the merge actually follows. This page is about where that line is drawn.

A correction, recorded after the decision was taken

I told you a TAKE of men leaves the fleet unjudged. That is out of date. It was true when ah-z73s.2 was planned; ah-dxfd.1 has since taught the walk to resolve a TAKE's source, so a take from a unit in the same hex is merged exactly like a gift. Only a TAKE FROM a unit the hex does not show still leaves the taker unjudged. Several doc comments in the code still say the old thing and are stale.

This makes the bead follow more arrivals than the question described, which strengthens rather than weakens the answer given here — and the clause chosen for the warning, “once the men joining the crew this month are counted”, was already true of a take. Nothing was re-asked; the record should be right.

What is already settled, and needs no answer from you

These follow from ah-z73s.2's own decisions and are not being re-opened.

  • Men given aboard are counted. The fleet is judged on the merged sailing level — which can go up or down — instead of the check falling silent.
  • Men TAKEn aboard from a unit in the same hex are counted — see the correction above. Only a TAKE FROM a unit the hex does not show leaves the taker unjudged.
  • A guessed headcount stays unjudged, and so does a unit whose sums the ledger could not follow. Both already silence this check today and still will.

The one case that is genuinely open: recruiting

rules/buy: “Recruit 5 barbarians into the current unit. (This will dilute the skills that the unit has.)” and rules/economy_recruiting: “New recruits will not have any skills or items.” So recruits are an arrival whose effect on a skill is exactly computable — unlike a TAKE, where the source unit's skills are genuinely unknown.

A Raft that states Sailors: 2/2, crewed by two gnolls who each know sailing 1:

  SAIL N
(2×30 + 4×0) / 6 = 10 points → sailing 0. Levels aboard: 0 × 6 = 0. The raft needs 2.
