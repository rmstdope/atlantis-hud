Ordering historical matches in the palette

Chosen: A. Historical matches carry a clear “last seen turn” marker and remain in one relevance order with current matches. The best match can therefore be first, whether or not it is current.

A — chosen One relevance order

Current and historical matches stay together. The best name match is first, with the marker explaining its age.

When only historical matches exist

Both choices: historical matches remain searchable even when no current match exists. In A, they remain in the normal list. In B, the list has only the “Previously seen” heading; it does not say “nothing matches”. The palette continues to close on selection, Esc, or a click outside, and nothing is saved by the search.
