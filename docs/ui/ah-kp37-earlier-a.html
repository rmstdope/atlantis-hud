ah-kp37 — Option A: the list lives inside the world popover

You can already fetch this turn from a New Age world (ah-lbd9.3, shipped). This bead adds the other turns the world still holds, so a turn you never kept a file of can be pulled into the game's stored history and compared against. An earlier turn is stored, never shown — the same rule a dropped older file already follows.

In A the world popover drills in: the second item swaps the popover's body for the list of turns, with a way back. Clicking a turn fetches it, and the popover closes — one turn per visit, exactly like "Fetch this turn's report" behaves today. Compare with B, where the list is a dialog you can fetch several turns from before closing.

5 · What A costs, and what it buys

Buys: no new surface at all — one popover, one item, the same drill-in you would find in any menu. Escape closes it like every other popover; there is no focus trap and nothing modal to get out of.

Costs: one turn per visit. Back-filling four turns means opening the popover four times, and the popover is 288px wide, so a long list scrolls inside it.
