Order suggestions — what you typed first, then A→Z

Chosen: if what the player typed is exactly a whole entry (case ignored), it is the first suggestion, so Enter picks it. Everything else is A→Z by the short code on the left, case ignored, a word before the longer words that start with it. Where one position offers both the order's own words (keywords, item classes, directions) and names (items, skills, buildings, ships), each group is sorted on its own, the order's words first, with a thin line between. Lists of units and targets are not touched. Nothing else about the popup changes: same keys, same size, same rows.
