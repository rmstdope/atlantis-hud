The edges — every state the happy path hides

Nine states, with the wording I propose for each. These are the same under Words A and Words B — they are the refusals and the odd cases, not the success line. Tell me which of them you would word differently.

E1 No report ever loaded — you settled that this refuses

no report loaded
could not read map-turn-71-level-1.txt: a map export adds to a map you already have — load a turn report first
  • Says what to do, not only what went wrong. Red dot, and the app’s existing could not read <file>: prefix.

E2 A map export naming a faction you have no game for

You are playing game 7; the file is from a faction you have never seen. Under “trust the turn numbers” this is just an ally you have not met.

Borg TNG (95) turn 71

someone-map.txt is a map export from The Disinherited Knights (42), written on turn 71. It holds 40 hexes and nothing else — no units, no orders, no events.

  • Treated like any other ally. Nothing distinguishes a stranger from an ally in the file.
  • If you would rather this warned, say so — it is the one place “trust them” could bite.

E3 A map export whose header carries no date

Possible today: the exporter writes the date line only when the source report had both a month and a year. Without a turn there is nothing to stamp the hexes with.

Borg TNG (95) turn 71
could not read map-level-1.txt: the map export does not say which turn it was written on
  • A map-export-specific message rather than the generic the report does not name its turn, which would send you looking for the wrong thing.
  • The plan also stops this file being produced in the first place — see E9.

E4 A map export of level 2 while you are looking at level 1

Borg TNG (95) turn 71 · surface
added 14 hexes from Mantzikert (39)’s map export — 14 new to your map
surface — unchanged
  • The hexes land on their own level and the view does not move. Levels are part of a hex’s identity, so nothing special is needed.
  • You will not see anything change until you switch to the underworld. Say if the status line should name the level.

E5 A map export holding no hexes at all

Exporting a rectangle you have never visited already warns No regions you have visited lie inside this rectangle. — but the file can still be saved.

Borg TNG (95) turn 71
could not read map-turn-71-level-1.txt: the map export has no hexes in it
  • Refused before the prompt — there is nothing to ask about.

E6 Cancel, and Escape

Borg TNG (95) turn 71
11 regions · 34 units
your map — 11 hexes, unchanged
  • Escape and Cancel do the same thing: the prompt closes, nothing is written, and the status line goes back to whatever it said before the import.
  • Focus returns to the Import button, so a second attempt is one key away.
  • Same as the existing foreign-report prompt, which is also dismissed by Escape and says nothing on cancel.

E7 Two map exports chosen at once

Two files is a batch, and you settled that a batch adds them without asking.

Borg TNG (95) turn 71

Nothing was imported. Turn 71 is on screen.

ally-map.txt — map export, 8 hexes added
other-ally-map.txt — map export, 3 hexes added
  • “Nothing was imported” is the existing headline when no turns landed, and it reads as a failure here. I would make it 11 hexes added to your map from 2 map exports.

E8 A file that only looks like a map export

Someone hand-edits a report and leaves ; Map export from Atlantis HUD at the top.

  • Treated as a map export: the marker is the whole test, and it is on the first line the exporter writes.
  • The worst outcome is that a real report’s hexes are added to your map instead of opened — nothing is lost, and the prompt names the file, so it is visible.
  • The marker is matched on the first non-blank line only, so a report merely containing that text further down is not caught.

E9 The export side — stopping a bad file being written

An export from a report with no faction or no date produces a file nothing can import. Today it saves silently.

Borg TNG (95) turn 71

This turn’s report does not name its faction, so a map exported from it could not be imported by anyone — including you. Export is unavailable for this turn.

  • Fails where the mistake is made, rather than in the recipient’s client a week later.
  • This is the only part of the plan that touches the export dialog. Say if you would rather it warned and let you save anyway.
