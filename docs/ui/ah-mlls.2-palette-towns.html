For and against

  • Reads the way structures already read in the palette: Lunar Mine [17] · cavern (3,41).
  • Typing city (or village) lists every one you know of: a quick way to see where the cities are.
  • The size is in square brackets the way the turn report prints it: contains Akroitos [city].
  • Rows are a little longer, so on a narrow window the province is cut off sooner.
