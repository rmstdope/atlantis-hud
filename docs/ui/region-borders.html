ah-f9c — Emphasize province borders (the “Regions” badge outline)

Chosen: Option B1 — dashed 3px screen-constant line in each theme’s own ink over a solid 5.5px ground-coloured halo, dashes 9 5, visible at every zoom, no new setting. Options A, B2, C and “current but stronger” were considered and rejected; the interview is recorded in bead ah-f9c’s design field.

Today the province outline is one shared rule: 1.2 world-units wide, dashed, 70% opacity, app-grey — the only stroke on the map that thins as you zoom out (0.3px on screen at minimum zoom), while every theme’s hex edges stay a constant 1.0–1.6px. Each variant below is shown over three theme backgrounds (Cartographer’s Table parchment, Tactical HUD panel, Miniature World board) at rest zoom, and then the far-zoom strip shows how each behaves zoomed all the way out — which is where the current border disappears. Beveled Tile is not simulated but follows the same rule.

Current — for reference

Thin, dashed, grey, translucent, and scales with zoom: faint at rest, gone when zoomed out.

Option A — “Ink line”: solid, screen-constant, in each theme’s own ink

Solid 2px line that never thins, with a soft halo of the theme’s ground colour so it separates from the hex lattice. Cost: loses the dashed “overlay” look — reads as a firm cartographic border rather than an annotation.

Option B1 — Heavy dash at 3px

Dashed, screen-constant, theme ink, full opacity, 3px over a 5.5px ground halo. Dashes 9 5, so the pattern no longer matches the keyboard focus ring.

Option B2 — Heavy dash at 3.75px

Same as B1 but 3.75px over a 6.5px halo — unmistakable at any zoom, at the cost of some weight over small provinces.

Option C — “Bold ground line”: solid and 3× wider, but still scales with the map

Strong at rest and near zoom, and it shrinks with the terrain like a road does — but it still thins when zoomed out (≈0.9px at minimum zoom), which is where the complaint bites hardest.
