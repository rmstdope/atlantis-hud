Round 6 — who gets filled, and how the lines stack

Settled so far: S2 + V1 (wait only when it matters), W4-B + P1 (three sentence shapes, agreeing plurals), F1 (carry on and name the turns that failed), N1 (a turn imported now folds in now).

Two last things. The first is a behaviour fork the notice's own wording raises; the second is the stack, which now has four possible lines in it.

O An own unit that has no skills of its own

The rule agreed in round 1 is a derived skill never displaces a real one. That settles a unit that has skills. It does not settle a unit of your own that has none — a newly recruited unit that has studied nothing, or one remembered from an old turn where none were listed — and which turns up in a battle roster.

  • Your own report lists your own units' skills in full and every turn. A roster is at best as good and usually older — so for your own units it is a worse source, not a fallback.
  • An empty skill list on an own unit is the truth: it really has studied nothing.
  • Keeps the dialog honest — every sentence it says is about units that belong to another faction, and the count matches exactly what was filled.

  • The notice counts only foreign units, so a filled own unit is invisible in every sentence the dialog says.

L The order of the notice lines

There were three kinds; there are now up to four at once. Today's order is remembered, foreign, empty side, and the marker is brass for a caveat and grey for the empty side.

L1 — the new lines sit with what they qualify   recommended
14 units will be exported.
2 units were not in this turn's report. They go out as they were when last seen.
6 units belong to another faction. 4 of them go out with combat skills read from battle reports; the other 2 go out with none.
2 stored turns could not be read. Any battle in them was not counted.
The defending side will be empty.
  • The “turns could not be read” line sits directly under the sentence whose count it qualifies, where it is read as qualifying it.
  • While the scan runs, the grey Still reading this game's battle reports… line takes the foreign line's place — same slot, so nothing below it moves when it is swapped out.
  • Markers: brass for both new caveats except the transient waiting line, which is grey like empty side — it is not a caveat about the file, it is a state that is about to end.
