Units that do nothing this month — proposals (bead ah-dwk6)

A unit given no month-long order spends the month doing nothing, and one unit is easy to miss among many. The bead asks for a warning — and asks the planner to settle which units should be exempt, since “a warning on every one of them is noise”.

I measured the noise rather than guessing at it. The numbers below are your own committed turn-71 orders — written by you, accepted by the server. That is the only honest evidence about how loud this check would be, and it changes what I would recommend.

§5  One thing I am deciding, not asking — but you should know it

The app does not understand every Atlantis order. ASSASSINATE, STEAL, TRANSPORT, DISTRIBUTE, SACRIFICE and others are recognised by the grammar but produce no intent, and an unrecognised line is silently dropped — so a unit ordered to assassinate looks, to this check, exactly like a unit ordered to do nothing.

Left alone that would make this the noisiest check in the app. So the plan records the lines it could not read, and the check stays silent whenever a unit has any order the app does not understand — it warns only when it has read every line and none of them spends the month. Fewer warnings, and none of them wrong.
