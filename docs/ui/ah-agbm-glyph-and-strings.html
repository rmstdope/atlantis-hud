Round 3 — the glyph, and every string as it will ship

You chose M1: the mark trails the item list. Two things are left, and both are things a player reads.

Each stage is the real column at its default 220px, showing a short list where the mark survives and a long one where it does not. That second row is M1's known cost and is drawn here so it is on the record.

G1 — a bare question mark

IDNAMEITEMS
*5530Traders1580 SILV, 4 HERB ?
*5531Caravan1580 SILV, 4 HERB, 12 LEAT, 3 SWOR, 40 WOOD ?
  • The exact glyph the Silver column already uses for a figure it will not guess at, so the player has met it before.
  • After a comma-separated list it can read as a stray item rather than a note about the list.

G2 — a plus and a question mark

IDNAMEITEMS
*5530Traders1580 SILV, 4 HERB + ?
*5531Caravan1580 SILV, 4 HERB, 12 LEAT, 3 SWOR, 40 WOOD + ?
  • Reads as arithmetic: this list, plus something unknown — which is exactly what it means.
  • Unmistakably a note about the whole line rather than another entry in it.
  • Two characters wide instead of one, so it is lost to truncation marginally sooner.

G3 — an ellipsis and a question mark

IDNAMEITEMS
*5530Traders1580 SILV, 4 HERB … ?
*5531Caravan1580 SILV, 4 HERB, 12 LEAT, 3 SWOR, 40 WOOD … ?
  • Collides with the truncation ellipsis the cell already produces, so a clipped list and an uncounted order look the same.
  • Drawn only to rule it out.
