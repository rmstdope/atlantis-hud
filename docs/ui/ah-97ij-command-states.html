the coupling you need to know aboutA refresh is not a docs change

packages/ruleset/src/committed.test.ts asserts that config/public/ruleset.json is exactly what the scraper produces from these two fixture files. So refreshing the pages without regenerating the ruleset leaves the repository red. And regenerating it changes movement costs, item weights and skill prices that the application actually uses — 171 items, 96 skills, 58 buildings.

There is a second edge. docs/ruleset-contract.md sets the policy that movement values fail loudly: rules.ts anchors six regexes on the page’s own sentences and throws RulesetScrapeError rather than defaulting, because “a movement number that is quietly wrong produces routes that are confidently wrong, which is worse than no planner at all.” A reworded sentence therefore makes the refresh fail, not merely differ.

$ pnpm run atlantis refresh

  movement.terrainCosts.doubled  +jungle
  items.MSWO.weight              2 → 3
  skills.MINI.cost               10 → 12

the planner routes with.

question 1What the weekly job produces

AOne PR, fixtures and ruleset togetherrecommended

The job refreshes both pages, regenerates ruleset.json, and opens a single PR. The repository stays green and you review one diff.

  • Green at every commit; nothing is ever half-refreshed.
  • The rules diff and the numbers it moved sit side by side in one review.
  • A PR that changes real application behaviour arrives unbidden — it needs reading, not rubber-stamping.

BA bead, and no commits at all

The job commits nothing. It files a P4 bead saying the pages moved and what changed, and the refresh happens as planned work like anything else.

  • Nothing lands without a person having decided to do it.
  • Fits the workflow you already have.
  • The snapshot stays stale until the bead is ranked, planned and built — days, while agents look up the old rules and believe them.

CA PR with the fixtures only, deliberately red

Refresh the pages, leave ruleset.json alone. committed.test.ts fails, which is the point.

  • Impossible to merge by accident.
  • A red main branch blocks every other PR until someone fixes it.
  • Punishes the whole fleet for a change on someone else’s website.

question 2When the page is reworded and the scraper throws

The pages differ, but rules.ts cannot find one of its six sentences, so it throws and refuses to write a number. There is no PR to open, because the ruleset cannot be regenerated.

AA P0 bead, naming the sentencerecommended

File a P0 with the RulesetScrapeError message and the sentence that moved. The fleet picks it up like any other P0 — which, per the buffer rule, is immediately.

  • The one case where the app’s movement numbers cannot be regenerated is the one that gets planned first.
  • Lands in the queue that is already watched.
  • No diff to look at until someone opens the bead.

BA PR with the fixtures only, plus the error

Open the PR anyway, red, with the scraper’s error in the body.

  • The diff is visible immediately.
  • Same red-main cost as 1C, for a case that is rarer and harder.

CA GitHub issue

File it in the external inbox instead, so Moira triages it with you.

  • Goes through the triage you already run.
  • The inbox is for external reports; this is the fleet talking to itself.

question 3The “No skill report.” noise

Most skills define one useful level and leave the rest as the literal string “No skill report.” — of the 480 skill entries, the great majority are that. Printing them costs context and teaches an agent nothing.

ACollapse them into one linerecommended

data MINI prints levels 1, 3 and 5 in full and ends with levels 2, 4: no skill report.

$ pnpm run atlantis data MINI
# data/skills — mining [MINI]

mining [MINI] 1: This skill deals with all aspects of extracting
  raw metals and gems from the earth. … may PRODUCE iron [IRON]
  at a rate of 1 per man-month. Costs 10 silver per month.

mining [MINI] 3: … may PRODUCE mithril [MITH] at a rate of 1
  per man-month. … may BUILD a Mine from 10 wood [WOOD].

  man-month. … may BUILD an Alchemist Lab from 10 admantium [ADMT].

levels 2, 4: no skill report
  • Says the level exists and is empty — which is itself a fact about the game.
  • Cuts a typical skill lookup by more than half.
  • One more rule in the output format to explain.

BPrint every level verbatim

Exactly what the page says, including the empty ones.

  • Nothing is interpreted; the output is the source.
  • Four fifths of a skill lookup is the same sentence repeated.

question 4What it is called

Two names, and both are yours because both become vocabulary. The command goes into CLAUDE.md, where every session reads it and every agent copies it forever. The skill name is what appears in the skill list.

SkillCommandReads as
