ah-t2i — Right-click centres the map on a hex

Both figures are live. Right-click any hex to centre the map on it (the browser menu is suppressed inside the figures, as it would be over the real map). Left-click selects — the white double ring — exactly as in the app. Today right-click does nothing at all in the app, so this gesture replaces nothing.

Decisions (recorded from the planning discussion): instant jump (variant 1); right-click centres only, the selection stays put; Ctrl+click on macOS is treated as right-click and centres; a right-click always centres — known hexes and unexplored ground alike, even when the hex is already visible; the native context menu is suppressed over the map; help-overlay row — description "Bring a hex to the middle of the view", mouse "Right-click it", no keyboard chord.

Variant 1 — instant jump — CHOSEN

The view snaps to the new centre, like every map movement today (pan release, selection-follow, zoom-to-fit are all instant). No new machinery.

Variant 2 — short glide

The view glides to the new centre over ~250ms — the eye keeps its bearings on a long jump. New animation machinery on the map transform, disabled under reduced-motion; every other map movement stays instant, so the map gains two speeds.
