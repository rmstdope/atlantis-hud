Q3 A map export among twenty files — the batch importer asks nothing by design

Drag a folder in and the batch importer plans everything up front, then runs it and shows one summary. There is no prompt anywhere on that path. A map export in the pile has to do something.

B1 — added, and counted on its own line

t69.rep — imported as turn 69

  • A folder of everything an ally sent you just works.
  • Safe: adding hexes can never destroy anything, which is why no prompt is owed.
  • It is the one place a map export lands without being asked about.

  • “It always asks” holds without exception.
  • You have to notice the line and re-import the file by hand.
  • A folder of an ally’s files silently does less than you asked.

Q4 What a borrowed hex remembers

The export already writes ; last seen turn 40, 31 turns before this export above each remembered hex, and nothing has ever read it. Today every hex in an imported file is stamped with the file’s turn. Here is the same hex, before and after the fix — the ally saw it on turn 40 and exported on turn 71.

Today — the panel states a falsehood
mountain (12,48) in Cadaver
Last seen turn 71 — this turn
2 units · 3,410 peasants (hill dwarves)
  • You were never there, and nobody has been since turn 40 — but the hex reads as current.
  • The map shades it as fresh, and Not seen since turn… never fires.
After — the file’s own comment is finally read
mountain (12,48) in Cadaver
Last seen turn 40 — 31 turns ago
2 units · 3,410 peasants (hill dwarves)
  • Identical to how your own remembered hexes already read — no new component, no new words.
  • The map’s age shading and the stale banners become true for borrowed hexes too.
  • A hex the exporter saw on the export turn carries no comment and lands at the file’s turn, as now.
The question is whether the exporter’s turn numbers mean anything in your game. They do when you are both in the same game — turn 40 is turn 40 for everyone in it, which is the only case a map export is meant for. A file from a different game would put its turn numbers into yours, and nothing in the file says which game it came from.
