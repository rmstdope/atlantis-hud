ah-rgkk.1 — one popup, for the cell under the pointer

The units table has two hover mechanisms today: a rich portal tooltip for the whole unit (skills, items, silver, battle skills), and the browser’s own title on nine individual cells. This bead replaces both with a single popup that knows which column the pointer is on. This page settles the shape; the rest of the family (ah-rgkk.2–.5) fills each column’s content into it. Everything drawn here uses invented but realistic report material.

A — What the popup is headed with

The pointer is on Braves (1487)’s Items cell. The row is right there under the popup, and the popup is opened by resting on that row — so does it need to name the unit at all?

C — Moving sideways along a row

The pointer rests on Skills, the popup opens; then it slides one cell right onto Items without leaving the row. Today’s tooltip never noticed, because it only knew the row.

C1 — swap the contents in place, no second wait
0 mspointer enters the Skills cell 300 mspopup opens: Skills, anchored where the pointer rested +1 spointer moves onto Items in the same row instantlythe same popup now reads Items; it does not close, and it re-anchors to the new cell  pointer leaves the row → popup closes
  • Reading a row column by column costs one 300 ms wait, not one per cell.
  • Feels like one object that follows attention.
  • Crossing a row on the way somewhere else flickers content through several columns.
C2 — close, and wait again
0 mspointer enters the Skills cell 300 mspopup opens: Skills +1 spointer moves onto Items → popup closes at once +1.3 spopup opens again: Items  pointer leaves the row → popup closes
  • One rule for every move: rest 300 ms, and only then does anything appear.
  • Nothing flickers — crossing the table shows nothing at all.
  • Comparing two cells of one unit costs a deliberate pause per cell.

D — What becomes of the whole-unit summary

Today’s portal tooltip shows everything — every skill, every item, the silver working, recovered battle skills, the dissolving note — wherever in the row the pointer rests. Per-cell popups replace it in the Skills, Items and Silver columns. The question is whether it survives anywhere.
