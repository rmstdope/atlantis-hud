Who the spare-teacher warning is about — proposals (bead ah-vw63)

Your words, during the ah-dwk6 replan: “teaching warning should only be on units actually TEACHing this month. Only warn if they have free slots. Not someone not teaching.”

You ranked it P0. This is not a narrowing of an edge case — it changes what the check is for, so I want you to see the new purpose stated before I write it down.

§1  What it does today

offer_free_slots (semantics.rs:1284) runs for every unit in the hex. The only thing standing between a unit and this warning is is_busy() — so any unit whose month is not otherwise spoken for, and which out-ranks a studying unit in that unit's skill, is told it has teaching slots free.

plain (12,34) — today1
⚠500this unit has 30 teaching slots free and could teach unit 700
unit 500 ; (no orders at all — a level-3 combat veteran, parked) unit 700 STUDY combat
Unit 500 was never asked to teach anything. It is a parked unit that happens to know combat. The warning reads as though it had a teaching plan with room in it.

§2  The consequence you may not have considered — and it argues for the change

ah-dwk6 now covers the case this check was invented for. Its original purpose (its own comment says so) was “a teacher with slots to spare while somebody studies untaught” — i.e. spot the idle skilled unit. But a unit with no orders now raises “has no order that spends the month” from ah-dwk6, on the same unit, in the same list. So unit 500 above is still caught, by the check that is actually about being idle. Narrowing this one loses no coverage; it removes a duplicate that was wearing the wrong label.

§3  What it would do instead the same hex, with 500 actually teaching

A Keep the wording

  • No new string to agree; the sentence is already true of a real teacher.
  • “could teach” reads oddly for a unit that is teaching — it sounds like it is not.

B Say it is already teaching

plain (12,34)1
⚠500has 20 teaching slots still free and could also teach unit 900
  • “still free” and “also teach” both say the unit already has students.
  • Drops “this unit”, which the unit number already supplies — matching every message the two new warning beads added.

C Lead with the waste

plain (12,34)1
⚠500is teaching 10 of the 30 students it could take; unit 900 studies untaught
  • Most informative — names both numbers and the consequence.
  • Longest, and a semicolon is a construction no other message here uses.
unit 500 TEACH 700 unit 700 STUDY combat unit 900 STUDY combat ; 900 studies untaught, and 500 has room
