ah-grgn — chosen behavior, edge states, and final words

Chosen: warn whenever the studied magic skill's next level is above at least one prerequisite's current level. Accumulated days do not change whether the warning appears.

Also studying magic above level 2 outside shelterBoth independent warnings remain; disabling either setting removes only that warning.

Three or more blockers

The warning repeats each requirement so every prerequisite remains attached to its required level. This is longer than grouping equal levels, but stays unambiguous when levels differ.

Exact setting words

Studying/Teaching
Magic study capped by prerequisites
A mage ordered to study a magic skill whose next level is blocked by prerequisite skills.
Interaction contract
  • On by default, like every narrow advisory except Unguarded hexes.
  • The checkbox is keyboard-focusable and Space toggles it.
  • Turning it off immediately removes this code from counts, panels, and editor underlines on the next validation.
  • There is no Cancel state: warning toggles persist immediately, as they do today.
  • At narrow width, message and setting description wrap; neither truncates.
