Settings → About — what the app says it is

Settings → About shows a Version row, a Build row and the update button. Nothing tells a player what Atlantis HUD is, what it needs to work, or where to report a problem. You supplied the copy and invited suggestions; Cerebro proposed a revision it explicitly did not treat as decided. Below are both, plus a third, in the dialog as it actually draws.

One of Cerebro's changes is about accuracy rather than style, and it is the reason this is worth a real look: "a web based client" is not true of the build most people will read it on. v0.10.0 shipped macOS, Linux and Windows bundles, and the Build row directly above the sentence names the platform — so a player on the Windows desktop app is told something the line above it contradicts.

2 · The variant sentence — a fact, or read from the build?

packages/shared/src/rulesets.ts already holds the answer: RULESETS is a list, each with a label, and today it has exactly one entry labelled NewOrigins. So the sentence can be written or it can be read.

iWritten as a sentence

"At the moment only the New Origin variant is supported." — plain prose, in the file with the rest of the copy.

To work properly it needs the rules and game data for the particular Atlantis variant you are playing. At the moment only the New Origin variant is supported.

  • Reads as English, and can be phrased however you like
  • Goes stale silently the day a second ruleset is added
  • "New Origin" here, NewOrigins in the code — two spellings of one thing

iiRead from what the build ships

The variant names come from RULESETS. Adding a second ruleset is already "a scrape and a line here" — and this sentence updates itself when that line lands.

To read your reports it needs the rules and game data for the Atlantis variant you play. This build has NewOrigins.

with two shipped, the same sentence reads
… This build has NewOrigins and Otherworld.

  • Cannot go stale — no one has to remember to edit this tab
  • One spelling of the variant's name, everywhere in the app
  • The sentence has to survive one, two or five names, so it is stiffer prose
  • NewOrigins is how the code spells it; if you prefer "New Origin" the label changes too
