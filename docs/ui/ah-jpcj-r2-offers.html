The map-export prompt — Offers A: add it, or don’t

One prompt, two buttons, and it is the same prompt whether the file is yours or an ally’s. You chose that a map export dropped on an empty HUD is refused — so a map export is never a thing you can open. Offers A takes that to its conclusion and stops offering to open one at all. What is left is a confirmation: Add to map or Cancel.

Settled in round 1. A map export is a report and it always asks (B). An empty HUD refuses it. A map from another turn still lands. Per-hex staleness is in this bead.

1 An ally’s map export, same turn

Borg TNG (95) turn 71

map-turn-71-level-1.txt is a map export from Mantzikert (39), written on turn 71. It holds 19 hexes and nothing else — no units of theirs, no orders, no events.

Add to map takes every hex in it your own map does not already know more recently. You stay on Borg TNG (95), turn 71, and nothing you have is replaced.

your map — 11 hexes
  • The prompt states the one thing that matters and offers the one thing you can do.
  • Escape cancels, as it does on the existing foreign-report prompt.

  • Only the first sentence differs from an ally’s: from your own faction, Borg TNG (95).
  • Pressing Add to map is harmless — every hex is already known at least as recently, so nothing changes and the status line says so.
  • After Add to map: added nothing — your map already knew all 11 hexes at least as recently
What Offers A gives up. There is no longer any way to open a map export as a report — not your own, not an ally’s. If you ever wanted to look at an ally’s exported map as though it were their turn, that goes away.
Compare with Offers B, which keeps a third, destructive button on the prompt. Open both before choosing — the difference is one button and what it can cost you.
