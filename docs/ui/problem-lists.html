Telling a hex from a problem — the decided design (bead ah-uia)

The problems list mixed two kinds of line — the hex a problem is in, and the problem itself — and read as one undifferentiated run. Worst of all were the diagnostics that belong to a hex and to no unit (“nobody is guarding this hex”): they left the unit column empty, so they looked like headings.

Decided, 2026-08-17, over three rounds. A card per hex with a filled brass header strip, chosen over an indent-and-rule treatment and over a flat list with the hex on every row. A hex-level problem says hex in italics where a unit id would go. Severity is a glyph and a colour — ⚠ warning, ✕ error — in all four places the app draws a diagnostic. The region panel keeps the card and drops its head, since the panel header already names the hex. The colour now lives in the glyph alone — the message itself reads in ordinary ink, where today the whole message is amber or red, which made a hex of warnings a wall of amber. Long messages wrap; nothing is clipped. The card head is the click that jumps the map to that hex, and it advertises that on hover only.
