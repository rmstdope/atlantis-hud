The rules behind all of it

  • The shell is web unless the bead touches the desktop specifically — a cargo build is minutes of the navigator's patience for a React app both shells share.
  • A fixture is proved, never assumed. Parsed with the real parser, and the precondition the first decisive step depends on asserted, before a page is written.
  • Exploration is named and bounded — two or three specific things, what would count as wrong, and the sentence that says anything past them is a new bead.
  • The verdict lives in the terminal, never on the page: the page is a static file with no agent behind it.
  • Nothing about launching the app is written here. The commands, the ports and the fixtures doc are declared once in the project's own configuration and read from it.
