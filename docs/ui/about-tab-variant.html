About — saying which variants the build has

Settled: Cerebro's wording, spelled New Origins everywhere (the label in rulesets.ts changes to match), prose below the Version and Build rows and above the update button, and the variant names read from RULESETS rather than typed into the copy.

That last one is what still needs a shape. Cerebro's sentence — "At the moment only the New Origin variant is supported" — has the singular built into it, so it has to be written to survive a second entry. Each option is shown with one variant and again with two.

The three shapes

S1The sentence branches

Cerebro's line kept as closely as possible, with the singular and plural both written out and the right one chosen at render.

Atlantis HUD is a client for Atlantis, the play-by-email game. It runs in a browser and as a desktop app.

To work properly it needs the rules and game data for the particular Atlantis variant you are playing. At the moment only the New Origins variant is supported.

If you run into a bug or would like a feature added, please describe it on the project's issue page on GitHub.

with two shipped

… At the moment the New Origins and Otherworld variants are supported.

  • Reads as ordinary English in both cases — closest to what you approved
  • Two sentences to keep in step, and "only" has to vanish in the plural
  • Three variants needs an Oxford comma rule nobody will think about until then

S2One shape, always

A single sentence that does not care how many there are — the names are simply listed after it.

  • Any number of variants works without a thought
  • "Supported variants:" is a label bolted onto the end of a sentence
