The warning explains the restriction before saying that the unit has reached it. This is longer, but reads as a reason rather than only naming a limit.

Chosen: lead with the race restriction; name every limiting race even when the sentence wraps; name the actual level when the unit is already above its legal ceiling; name the global skill cap when it equals a race cap; preserve today's global-ceiling behavior when race data is unavailable.

When the report never shows the race's plural

A report can contain one human and never write "humans" anywhere. Atlantis HUD deliberately does not invent item plurals because many are irregular. The grammatical fallback names the singular race explicitly:

Unit and skillExact warning
One human; no "humans" elsewhere in the reportthe human race cannot learn observation past level 2, and this unit is already there

When the report has shown the plural, the approved "humans cannot..." form remains unchanged.
