ah-lyg6.2.3 — the schedule, redesigned: a cell is one turn

The grid is unchanged. What changed is how a plan is written into it: a cell holds one turn, you set it from a dropdown, and nothing else on the row moves. There is no queue of goals, no to level, no Set for a skill and no ghosted tail. The dropdown offers only what that mage will actually be able to study on that turn, plus teaching, plus a way to empty the cell.

The schedule

Mages down, the next six turns across. A cell says the skill and the level he ends that turn at; an unplanned turn reads —. Hovering or focusing a cell still shows the mage's skills for that turn, as it does today.

Setting a cell

Click a cell, or focus it and press ↵. The dropdown opens in place, on whatever the cell holds. Choosing a skill writes it and closes — there is no Set.
