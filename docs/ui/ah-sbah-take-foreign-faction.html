Option A - a dedicated TAKE warning

Cost: adds one precise toggle to Settings. A player can silence cross-faction TAKE mistakes without hiding unrelated item-transfer refusals.

Warnings setting

ONTaking from another factionA TAKE naming a visible unit from another faction, which the game will refuse.

Off suppresses only the warning. The forecast still refuses the transfer because toggles never change projected game behavior. The setting persists globally like the other warning toggles.
