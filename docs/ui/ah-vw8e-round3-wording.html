My mistake, and it changes a warning. Round 1's case table said that SELL ALL FUR EXCEPT 3 written twice warns on the second line. It should not: the unit still holds 3 furs there. That line sells nothing because its own EXCEPT holds back exactly what is left, not because the goods are gone — and a warning called nothing left to sell would be saying something untrue.

The gate this suggests

A line warns when the unit holds none of those goods by the time that line runs — the report's stock, moved by this month's gifts and takes and by the sales above it. Not merely “this line sells nothing”, which an EXCEPT can cause all by itself.
