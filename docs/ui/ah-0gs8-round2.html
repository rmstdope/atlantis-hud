Round 2 — the file the player gets

Settled in round 1: the editor simply opens for any own unit standing in the turn (no notice, no button, no placeholder); a new block goes under the unit’s own region banner; and a report with no template gets a #atlantis…#end skeleton silently. This page is the four things that decision leaves open, all of them visible in the exported orders file.

Q1 — the document has no banner for this unit’s region

The seeded skeleton has no banners at all, and a real template only carries a banner for a region that had a listed unit in it. Ordering 1656 in mountain (42,82) in Derngill when that banner is absent.

Q1a — write the banner too
#atlantis 62

;*** mountain (42,82) in Derngill ***

unit 1656
buy 1 humn
study forc

#end
  • A file built from nothing still reads like one the server wrote.
  • Ordering a second unit in the same region files it under the same heading.
  • The app is writing a heading the server did not; its wording has to match the report’s own line exactly or it looks wrong beside the real ones.
Q1b — no banner; just the block, before #end
#atlantis 62

unit 1656
buy 1 humn
study forc

#end
  • The app never invents text the server did not write.
  • On a no-template report the whole file is an unsorted list of units.

Q4 — the seeded header carries no password

A template from a report arrives as #atlantis 62 "secret". A skeleton we seed ourselves has no password to put there, because the report never carried one. Send Orders is unaffected — it asks for the password and writes it into the line. Plain Export is the case: the file the player mails by hand would be rejected if their faction has a password set.

Q4a — bare header, nothing said
#atlantis 62

unit 1656
buy 1 humn

#end
  • Correct for a faction with no password, which is what #atlantis 62 means.
  • A player with a password who exports and mails the file gets a silently ignored turn.
Q4b — bare header plus a comment above it
; This report carried no orders template, so this file was started from scratch.
; If your faction has a password, add it: #atlantis 62 "your password"
#atlantis 62

unit 1656
buy 1 humn

#end
  • The warning is in the file the player is about to mail, which is where they will be looking.
  • A ; comment is ignored by the server (rules/orders), and the two lines sit above #atlantis so the sniffer that recognises an orders file still finds it.
  • Two lines of ours at the top of a file the player may reasonably regard as theirs.
