A fresher blue plus ripples, in all ten map styles

Open sea on the left, land on the right, and a two-hex lake inland. The sea keeps the waves it already has. Lakes get a fresher blue and two still, round ripples.

Collective marks water with a three-letter code instead of a shape, so its lake gets a code of its own (shown as LAK; the exact code is one of the questions). Blueprint is blue all over, so its lake is a slightly greener ground, and the ripples do most of the work there.
