Option B — each map theme keeps its own mood, re-tuned so every biome is distinct

Each theme keeps roughly its own lightness range and colourfulness (dim Tactical HUD, pale light variants, parchment Cartographer's Table); the new palette decides each biome's hue and where it sits from dark to light. Where a theme's range was too narrow to separate 17 biomes it is widened just enough. Textures are off in every map below. Each pair shows today on the left and the proposal on the right, at far zoom. The number under each is how far apart the two closest biomes in the clash groups are (forest/swamp/jungle, the forests, cavern/tunnels/chasm, hill/wasteland/desert, tundra/mountain) — bigger is easier to tell apart; today most themes have a pair under 2, which is the forest-and-swamp problem players reported.

Cost: separation is a bit weaker in the dimmest and palest themes than in A, but each theme still looks like itself.
