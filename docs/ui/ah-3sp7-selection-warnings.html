Two classes where being right looks wrong

Both of these are cases where the application would now do exactly what the game does, and the result may still surprise the player. The question is whether either earns a sentence. Everything below assumes the twelve classes resolve; the rows show the units table as it would look while the orders are being written.

Case 1 — a class that selects sixty items and moves nine

Unit 900 holds twenty lions and a skeleton. rules/give accepts ALL MONSTERS; the game selects all twenty-one and then refuses every item whose entry says This item cannot be given to other units. Only the skeleton leaves.

unit 900
GIVE 901 ALL MONSTERS

Case 2 — a class that quietly includes your silver and your food

Unit 900 holds 400 silver, 12 grain, 3 swords and a horse. Every one of those is IT_NORMAL.

unit 900
GIVE 901 ALL NORMAL
OPTION A — say nothing; the rows are the answer

The preview already shows what happens. Nothing new is written anywhere; no finding, no hover sentence, no new doubt.

No warning. The silver moves and the SILVER cell shows the new figure.

  • Nothing new to word, translate, or keep true as classes change.
  • The row already tells the whole story — the lions did not move, the silver did.
  • A player who meant "give my monsters away" sees a row where nothing changed, and cannot tell that from the application failing to understand the order.
  • Silver leaving on ALL NORMAL is easy to miss in a busy hex.
OPTION B — warn only where the game will refuse

One new order-check finding, for the case where a class selects items the game will not move. Nothing is said about ALL NORMAL, because everything it selects really does move.

Case 2 — all normal
UnitMenItemsSilver

Depot (901)2400 silver, 12 grain, 3 swords, 1 horse450

No warning — everything selected really moves.

  • Catches a real mistake: ordering ALL MONSTERS over a stack of lions does nothing, and now says so.
  • Fires only where the game itself will refuse, so it can never be merely an opinion.
  • Silent for the eleven classes where nothing is ever refused.
  • A new finding, a new string, and a rule about when it fires.
  • Says nothing about the silver.
OPTION C — warn on both

  • Nothing expensive is ever given away silently.
  • Fires on a correct order that the player may well have meant, so it is an opinion rather than a fact — the shape of warning that gets ignored, and then hides the one that mattered.
  • Two new strings and two rules, one of which has to decide what counts as "expensive".

The states each option has to survive

  • Nothing selected at all — ALL TOOLS from a unit holding no tools. Under every option: nothing moves, and nothing is said. This is not the same as case 1, where the items exist and are refused.
  • Everything selected is refused — ALL MONSTERS over lions alone, no skeleton. Under B and C the finding still fires and says the order moves nothing.
  • No ruleset loaded — no class resolves, and every one of them behaves exactly as all fifteen do today.
