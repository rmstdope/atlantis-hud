Option A — its own switch, on by default

Like every other order warning: a player who discards from shared stock on purpose can turn it off. New entry outlined.

Settings, Orders group
Settings — Warnings — Orders
Taking from another faction
A TAKE from a unit of another faction, which the game will refuse.
Transfers a unit writes to itself
A GIVE or TAKE naming the unit that wrote it, which the game will refuse.
Discards from shared stock
A GIVE 0 that discards more than the unit holds, so the game throws away goods its sharing faction-mates hold.
