ah-twsa — a SAIL whose route nothing can read

The player types SAIL NRTH. Nothing is said. No red mark, no warning, no problem line — the order looks accepted. Underneath, every reader in the application throws the line away: the unit is given no route, is not counted as one of the fleet's sailors, and, having no readable order at all, is quietly credited the region's wage as if it had been set to WORK.

Why only this one: SAIL has two legal forms — SAIL N NW sails the fleet, and a bare SAIL means "I help crew it" (rules/sail). When the first word after SAIL is not a direction, the empty form wins with nothing consumed and the checker declares the line fine. MOVE NRTH and SAIL N NRTH are both flagged today; only SAIL NRTH — junk in the first position — slips through.

The choice what should SAIL NRTH be?

All three options change only what the player is told. In every one of them the fleet still does not move and the route is still not followed — that part is already true today, and no option here invents a route the player did not write.
