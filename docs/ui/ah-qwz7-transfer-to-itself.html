Warnings setting

ONTransfers a unit writes to itselfA GIVE or TAKE naming the unit that wrote it, which the game will refuse.

It sits in Settings > Warnings > Orders, immediately after Taking from another faction, and starts on like the other order advisories. Turning it off hides only the sentence; the forecast still moves nothing, because a toggle never changes what the game is projected to do.
