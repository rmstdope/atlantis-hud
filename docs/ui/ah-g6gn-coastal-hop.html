ah-g6gn — a fleet's route between two coastal land hexes

rules/movement_sailing, verbatim: “A fleet can move from an ocean region to another ocean region, or from a coastal region to an ocean region, or from an ocean region to a coastal region.” At least one end of every step must be ocean. Coastal to coastal is not one of the three, and the game refuses it.

The map's own rule (movement::plan::blocks) asks only about the hex being entered: water never stops a fleet, and land stops it unless that hex is coastal. So a hop from one coastal land hex straight into the next is drawn as a solid line and offered as a route — the application proposing a move the game will not make. ah-sefq already warns about the written order; this bead is the other half, and afterwards the two surfaces agree.

The case a fleet docked in a coastal forest, one hex from another coastal forest

Click the neighbouring forest and the planner offers SAIL SE, one point, one month. Write it by hand and the map draws it solid, which means “this happens”. It does not.

Question 1 when there is no way round at all, what does the planner say?

Take the ocean at (2,4) away and the two forests are still neighbours, still both coastal — and now unreachable from one another by sea. Today the planner answers with a route. After this bead it must refuse, and the refusal is a sentence the player reads.

B a refusal that names the rule

When the only thing in the way is the sailing rule, say so and name the step — the same trick the planner already plays for a walker stopped by the sea, which re-runs the search with the water rule lifted so it can say which hex it would founder at.

A leave the map's balloon blindness alone

B teach the map about flying hulls in this bead

Carry the fleet down into the route search so that a flying fleet is exempt from the water rules altogether — the map would then agree with Problems for a balloon, inland hexes included.
