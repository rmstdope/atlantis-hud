Trade-off

  • One message per line, worded the same way as the faction-0 case.
  • The editor's error count drops: this line is now a warning, like FACTION 0 NEW 1.
  • GIVE / TAKE with NEW 0 still show the old error, so the same mistake reads differently on different orders.
