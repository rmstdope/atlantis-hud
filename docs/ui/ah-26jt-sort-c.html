ah-26jt — variant C: Id also breaks a tie inside another column's sort

This is variant A plus one more thing: when the sorted column cannot separate two rows, Id decides, instead of the order the rows happened to arrive in. Six units on 0 silver, or a screen of unnamed scouts, then have an order that does not shuffle when a later turn is loaded.

What this costs
