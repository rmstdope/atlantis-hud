ah-20di — Columns in the units table can be hidden, from a Columns tab

Chosen. A sixth settings tab, Columns, between Per game and Warnings — the move the Warnings tab already made when nine toggles were too many for the Global tab. It holds one checkbox per hideable column and all three buttons, and the Global tab's Units table columns row (with its two reset buttons) moves here, so the Global tab is exactly as long as it is today and everything about the table's columns is in one place.

Nine columns are hideable: Faction, Men, Move, Flags, Skills, Items, Structure, Long order, Silver. The own marker (a 24px dot with no header), Id and Unit are always drawn — they are what identifies a row — so "every column hidden" cannot be reached and there is no empty state to design. The choice is remembered globally, beside the dragged widths and the dragged order it sits next to. The rejected variant grew the same checkboxes inside the Global tab instead.

Units table columns Puts the dragged column widths, or the order they were dragged into, back to how they ship.

Three buttons, three preferences. Show all puts the hidden columns back and touches neither the widths nor the order; each reset button stays confined to its own preference, for the reason the pair was split in the first place. The checkboxes stand in the shipped left-to-right column order, never in the player's dragged order — a settings list that rearranges itself is one nobody can learn.
