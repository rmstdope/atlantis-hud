Assistant changes — resizable (agreed)

Drag any edge or corner to resize; the edge lights up while held and the pointer changes, with no words. The size you set is a limit: a short list shrinks the panel to fit, more units grow it up to your size, then the list scrolls. It cannot shrink below about 20rem wide and the title bar plus one entry. Double-click any edge or corner to return to the original size. The size lasts until the app restarts. In a narrow window the bottom sheet resizes from its top edge the same way.
