Open — Q5: the five items no rule reaches

After your create … rule, five items are refused by nothing: PORT portal, MWAG magic wagon, GLID glider, HPOT healing potion, IENT imprisoned entity. Your rule makes them transportable. Drawn here so you can see what that means:

unit 5530
  transport 6857 1 MWAG

UnitItems
5530120 SILV, 40 STON 
hoverwas: 120 SILV, 40 STON, 1 MWAG Sends 1 MWAG to unit 6857.
  • A magic wagon and a glider are advanced items, not artefacts; a healing potion and a portal likewise; an imprisoned entity is a monster the game already refuses to hand over at all.
  • The alternative is to add these five by hand, which is a list in the code that the game's own data does not support and that would silently rot if the game changed.
