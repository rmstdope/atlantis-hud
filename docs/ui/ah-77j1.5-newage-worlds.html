The decision — Send, on a desktop build, for a New Age game

Send posts orders to the New Origins web form. A New Age world posts orders through a REST API with a bearer token instead, which is a separate bead (ah-lbd9) and is not built. So until it is, a New Age game has nowhere for this button to send to. The button already exists only on the desktop build, and already knows how to be off; the question is whether it should be off or absent.

AOff, and it says why

The button stays where it is, greyed, and hovering it explains. Same treatment the app already gives orders with no #atlantis line.

Header, right end
Export ▾ Send Sending orders to an Atlantis New Age world is not supported yet. Export the orders and upload them yourself. ⚙
  • The player finds out why, at the moment they look for it.
  • One string; no layout moves when a game is switched.
  • A permanently dead control in the header of every New Age game.

BNot there at all

Open a New Age game and Send is gone; open a New Origins game and it is back. Export still carries the orders out.

Header, right end
Export ▾ ⚙
  • No dead control; the header only offers what works.
  • Nothing says why it vanished, and a player who used it yesterday on another game may read it as a bug.
  • The header's contents change as games are switched.
