Question 3 — goods the game will not transport

rules/economy_transport: “Men (including Leaders), summoned creatures (including illusionary ones), ships, mounts, war machines, and items created using artifact lore need to be carried/sailed from one location to another by a unit.”

So transport 6857 2 HORS is a well-formed order the server will simply not carry out. The catalogue can already answer four of those five — men, mounts, ships and monsters (which is where war machines such as the catapult sit) are 87 of the game's 171 items, known for certain from the shipped ruleset.

The unit below is ordered to transport one thing that moves and one that cannot.
