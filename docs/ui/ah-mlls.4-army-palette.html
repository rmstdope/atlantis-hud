Your Armies in the palette

An Army is a named group of units you put together yourself and keep from turn to turn. Today you reach one only through the list of sources down the left of the units pane. Here, typing an Army's name in the command palette (Ctrl/⌘ K) lists it, and choosing it shows that Army in the units pane. Three questions, each with variants. The made-up game below has three Armies: Iron Guard (7 units, 5 seen this turn), Ironwood Raiders (4, all seen) and Reserve (no units yet).

Chosen: every option marked "recommended" — row A (name, count, "army"), choosing A (the units pane shows the Army, map stays), order A (Armies first with nothing typed); words A ("5 units" / "1 unit" / "no units this turn"); empty Army A (focus on the Army in the pane's list).

No game open, or no Armies made yet: no Army rows, nothing new appears. What finds one: only the Army's own name — not the names of the units in it (those already find the units themselves).
