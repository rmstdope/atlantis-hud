ah-3cs — A fixed size for the “Units in hex” pane

Chosen: 1A blank remainder · 2 Option 1 bare “12” · 3A “Fixed pane size” · 4R reserve everywhere. Ghost rows were rejected as busier than they earn; “max” disappears from the stepper while fixed mode is on because it stops being true; collapsing on an empty hex was rejected because it reintroduces the exact layout jump the option removes. The full interview is recorded in bead ah-3cs's design field.

Today the rows setting is a ceiling: a hex with 5 units gets a 5-row pane, a hex with 40 gets the full 12 and scrolls. The new option makes the pane always reserve the configured rows, so it stops changing height as you move from hex to hex (and the map stops re-fitting under it). Every pane below is set to 12 rows and shows a hex with 5 units. The outer 45%-of-window ceiling still applies in every variant — on a very short window a large fixed size is capped, same as today.

2 — The in-pane stepper's label

Today the stepper between − and + says “max 12”. With fixed size on, “max” is no longer true — the pane is exactly 12. Options for what it says while fixed mode is on (when the option is off it keeps saying “max 12”):

Option 1 — “12” (bare number) Option 2 — “rows 12” Option 3 — keep “max 12” everywhere, accept the small lie

3 — Where the toggle lives, and its words
