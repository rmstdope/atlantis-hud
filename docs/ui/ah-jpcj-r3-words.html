The words — Words B: the prompt tells you what you would gain

The number moves forward. The prompt works out how many hexes are actually new before you press anything, so the decision is informed; the status line afterwards is then one short sentence.

Settled. A map export always asks (R1 B); an empty HUD refuses it; a map from another turn still lands; per-hex staleness is fixed here. The prompt has two buttons — Add to map and Cancel (R2 A). In a batch it is added and counted on its own line (R2 A). Turn numbers are trusted (R2 A).

1 The prompt, an ally’s export

Borg TNG (95) turn 71

map-turn-71-level-1.txt is a map export from Mantzikert (39), written on turn 71. It holds 19 hexes, 8 of them new to your map.

Add to map takes those 8 and leaves the rest alone — you already know them more recently. You stay on Borg TNG (95), turn 71, and nothing you have is replaced.

your map — 11 hexes
  • You know what the file is worth before you take it — Cancel becomes a real choice rather than a formality.
  • The count has to be computed twice: once to show it, once to do it. If they disagree, the prompt lied.
  • Focus lands on Add to map when the prompt opens, and returns to the Import button when it closes.

2 The prompt when the file is worth nothing

Your own export back in, or an ally’s you already have. Words B can say so before you press anything.

Your own export
Borg TNG (95) turn 71

map-turn-71-level-1.txt is a map export from your own faction, written on turn 71. It holds 11 hexes, none of them new to your map.

There is nothing in it to add. Adding it anyway changes nothing.

An ally’s you already have
Borg TNG (95) turn 71

ally-map.txt is a map export from Mantzikert (39), written on turn 71. It holds 19 hexes, none of them new to your map.

There is nothing in it to add. Adding it anyway changes nothing.

  • The commonest disappointment — re-importing something you already had — is answered before you act.
