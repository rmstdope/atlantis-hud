The new check, as it appears in Settings

Every advisory order check is toggleable and carries a title and a description in the Settings dialog. The new refusal warning needs both. Shown in place, under Orders, beside the two existing GIVE-related entries so the wording can be judged against its neighbours rather than alone. The existing rows are dimmed; the new one is in brass.

It is on by default, like every check but one — hex-unguarded is the sole exception and stays so.

WORDING A — named for what the game refuses
Orders
✓
Reused FORM numbers
Two units formed in the same hex this month with the same NEW number.
✓
Gifts to units that are not here
A GIVE or TAKE naming a unit the report does not show in that hex.
✓
Gifts the game will refuse
A GIVE or TAKE of a whole class holding items that cannot change hands, such as most monsters.
✓
Overloaded units
A unit ordered to move carrying more than it can move with.
  • Reads as a sibling of "Gifts to units that are not here" — both are about a GIVE that will not do what it says.
  • The description names the commonest case without claiming it is the only one.
  • "refuse" is the game's act, not the application's, and a reader might expect the order to be rejected outright.

A GIVE or TAKE of a whole class where some of what it names cannot change hands, so only part of it moves.
✓
Overloaded units
A unit ordered to move carrying more than it can move with.
  • Describes what the player will actually see: a row that moved less than expected.
  • Makes no claim about rejection, so it cannot be misread as a syntax error.
  • Longer, and "less than they say" is vaguer about the cause than naming the refusal.

One thing this list has to survive

  • Turned off. The warning disappears; nothing else changes. The row still shows the lions staying and the skeleton leaving, and the SILVER cell still shows a figure — the check only ever explains, it never alters what is counted.
