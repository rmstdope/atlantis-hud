## A test asserting a file was written could not fail, because the stub served the bytes already seeded

**What happened.** `scripts/atlantis.test.ts`'s `it("rewrites every world's sources once all three
scrape")` asserted `files.get(fixture)` equalled the committed bytes, with a `fetchText` stub
(`servingCommitted`) that returned exactly what `fakeIo`'s `files` map was already seeded with. The
assertions were therefore true before `runRefresh` wrote anything. Deleting both `io.writeFile`
calls in `runRefresh`'s second loop left all 33 tests green. The review sub-agent found it by
mutating the source; running the suite never would have.
**Why.** A fake whose file map is seeded from the same fixtures the network stub serves cannot
distinguish "wrote the right bytes" from "wrote nothing" — the two states are byte-identical. The
plan's increment 7 specified this test as "all six fixtures in `files` carry the fetched bytes",
which reads as a real assertion and is one only if the fetched bytes differ from the seeded ones.
**Cost.** One review round, about ten minutes.
**Prevent by.** When a test asserts that something was *written*, make the written value differ
from what the fake already holds — here, appending a marker to every served source and asserting
the fixture holds the marked bytes. Then confirm it by deleting the write and watching that one
test go red; a write assertion that survives its own mutation is not a test.
**Seen before.** None found — `grep -rl "cannot fail" docs/retrospectives/` returns nothing.
