What's new for you in Atlantis HUD (v0.20.1)
=============================================

## Fetching from a New Age world

- Fixed a bug where fetching "this turn's report and every earlier turn" from Arcanum or Trident brought down only the latest turn and said the world had no report for you
- When there are no earlier turns to fetch, because they are already loaded or the world has none, you are told so instead of being shown an error
- If the world's list of earlier turns cannot be understood, the message now says the fault is Atlantis HUD's and that trying again will not help
