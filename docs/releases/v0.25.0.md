What's new for you in Atlantis HUD (v0.24.0 -> v0.25.0)
========================================================

## Map sizes and levels

- When you create a world, you can now set a size for every map level the game has: Surface, Underworld, Underdeep and Dungeon
- New Age games start with the published sizes filled in (Surface 64 x 64, Underworld 48 x 48, Underdeep 24 x 24, Dungeon 128 x 32), and wrapping is one shared choice for every level
- You can change the size of every level of an existing game from its settings, in one window
- A game's settings now list each map level's size, and the wrapping, on lines of their own
- Movement, distances and the map view underground now use that level's own size instead of the surface's
- Fixed a bug where a game's width, height or wrapping could not be set once a size had been left empty: the value you typed was cleared as soon as you left the field

## Writing orders

- New units formed and moved in the same turn now appear at their destination, including a hex the map already knows about, with their orders ready to inspect and edit
- In Trident games, FACTION MARTIAL 2 MAGIC 2 is now accepted as a valid four-point allocation instead of being warned as over the limit
- In Trident games, FACTION now correctly refuses an allocation that leaves Martial or Magic with zero points

## Your units' silver

- The Silver column now shares a short food supply between CONSUME FACTION units in the same order as the game, including after food is produced and sent away, instead of leaving their result unknown or counting food that has left

## Your units' items

- An item a unit produces and uses up in the same turn still appears in its hover, with an explanation of why none is left at month end
