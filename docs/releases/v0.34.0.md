What's new for you in Atlantis HUD (v0.33.0 -> v0.34.0)
========================================================

## Moving to the new address

- Atlantis HUD has moved to [atlantis-hud.rmstdope.eu](https://atlantis-hud.rmstdope.eu): if you still play at atlantis-hud.kurelid.se, a dialog now tells you so at every launch, and its "Save all my games" button saves a backup of every game so you can import them at the new address (reported in [#1913](https://github.com/rmstdope/atlantis-hud/issues/1913))

## Games

- Import game backup has moved from the This game menu to the Games menu, as "+ Import game backup" just below "+ New game", since it brings in a game rather than adding to the one you have open

## Units

- Fixed a unit with weapon preferences in the report, such as "Ready weapons: pike [PIKE], sword [SWOR]", showing only some of its skills (reported on Discord)
