What's new for you in Atlantis HUD (v0.20.0)
=============================================

## Map and movement

- Where a report proves there is no exit between two neighbouring hexes, the map draws a wall along that side, in every map style
- Point at a wall to highlight it and see which hex's report proves it
- The route planner never plans a route through a wall
- A MOVE order drawn into a wall stops at the wall with a short red bar, and nothing after that step is drawn
- The Problems list warns about each MOVE order that would walk through a wall, and names the side and the hex
- In a Trident game, drawn routes and the orders preview now read your orders by Trident's rules, so a comment after a semicolon no longer changes where a unit goes

## Writing orders

- A SELL or BUY order written with EXCEPT is marked as an error, because the game ignores the EXCEPT and sells or buys the full amount
- The SILVER column counts such an order the way the game will carry it out, with the reserve ignored

## Web version

- In a New Age game (Arcanum or Trident), the web version can now fetch this turn's report, fetch earlier turns and send your orders, just like the desktop app
- If the world cannot be reached when you sign in, the web version tells you that either the server is down or it does not accept the web address you are using
